## 0. 一句话结论

**可行，但属于一个独立的、晚于当前 Cycle 的候选方案。** 现有 Politeia 框架在
「文化向量 `c⃗` + 忠诚度/层级 + 序参量」这条链上已经为「教化」预留了可复用的机制载体；
缺口在于「规范」不是一个独立维度、以及「教化者」这一方向性、非局部传播源尚未建模。
技术上改动量小、算力同阶；科学上只能给出**生成性/机制类比**结论，不能给出
「孔子→中国统一」式的历史因果结论。建议先跑一个最小可行验证（MVP）再决定是否扩展。

## 一、科学问题重述

### 1.1 想法的直观表述

用户的想法：**教化可以影响文明的发展**，例如中华民族中孔子、孟子的教化深刻塑造了
中国文明的走向。希望用数值模拟的方法检验这一命题，并落到本项目（Politeia /
AR-Politeia）的框架内。

### 1.2 转译为可计算命题

「孔子、孟子影响了中华文明」作为历史陈述无法直接被模拟。它必须先收缩成一个
**可计算、可证伪的机制命题**。在本框架（用户已选主线：**规范/道德**）下，命题收缩为：

> 在资源总量、地形、人口数、技术初始值均匹配的条件下，一个「教化者」群体——他们
> 传播一套有方向的道德/行为规范，而不是单纯地传播知识或占有资源——是否足以改变
> 文明在稳态下的宏观结构（政治统一度、独立实体数、层级深度、文化统一度、财富结构）？

换句话说，检验的不是「孔子对中国的历史贡献」，而是：

> **「方向性的规范传播」是否是文明凝聚力与秩序结构的一个充分条件性机制？**

### 1.3 该命题在框架内的三个可检验断言

| 断言 | 可观测含义 | 核心序参量 |
|------|-----------|-----------|
| A. 教化提升合作效率 | 同等条件下，被教化的群体在资源交换/生产上更高效、内部摩擦更小 | 财富总量、总财富漂移、Gini 轨迹 |
| B. 教化提升秩序稳定 | 被教化的群体形成更少、更深、更稳定的政治实体，叛乱率更低 | 独立实体数 C、层级深度 H、平均忠诚度 ⟨L⟩、叛乱率 |
| C. 教化加速文化统一 | 被教化的群体文化方向更快趋同，文化序参量更快接近 1 | 文化序参量 Q、文化关联长度 |

三者可分别消融（见 §3.5），从而回答「教化通过哪条通道起作用」。

## 二、现有框架契合度盘点

### 2.1 可复用资产（已核实的代码事实）

Politeia 的核心状态向量 `Z_i = (x, p, w, c⃗, ε)` 中，**文化向量 `c⃗` 已经承载了

### 2.2 关键缺口（必须新增的能力）

| 缺口 | 现状 | 对「教化」的必要性 |
|------|------|------------------|
| 无独立「规范」维度 | 文化 `c⃗` 只有「模=知识、方向=身份」，无「应然/规范」语义 | 教化区别于纯文化扩散的本质 |
| 无「教化者」角色 | 文化传播是对称、局部、被动的（邻里同化） | 教化是方向性、非局部、主动的传播 |
| 无「规范→行为」调制通道 | 规范不反作用于交换/忠诚/生产等行为规则 | 教化要"改变行为"而非只"改变观念" |
| 当前 Cycle 关闭上层机制 | Cycle 1 显式关闭文化/技术/忠诚/征服 | 本方案依赖这些模块，需等其稳态修复落地 |

> 注意：当前 Cycle 1 的 `question.md` 明确「关闭上层机制：文化、技术跃迁、忠诚、征服、
> 税收」，且 `exchange-kernel-design.md` 记录交换核仍在做稳态修复（候选 C，Cycle 3）。
> 因此「教化」方案**不能**在当前 Cycle 上叠加，必须等交换核稳态基线可靠后再独立开展。

## 三、核心建模方案（主线：规范/道德）

### 3.1 「教化」在本框架中的最小定义

「教化」的机制本质可拆为三点，缺一不可：

1. **方向性**：传播的不是无方向的知识扩散，而是指向某个「规范方向 ê_norm」的牵引力
   （如"仁、义、礼"指向的群体秩序规范）。
2. **非局部 + 主动**：教化者（孔子、孟子式人物）不依赖物理邻近，而是通过教学/著述
   跨越空间传播——这是对现有对称邻域同化的关键扩展。
3. **行为后果**：规范内化后必须改变个体的**行为规则**（更合作、更忠诚、更守序），
   否则「教化」与「文化标签」无区别，命题退化。

### 3.2 规范维度：推荐方案 A（方向性投影，不新增自由度）

遵循项目「不可约自由度」哲学与「派生量优先」原则（见 research-proposal §2.3），
**推荐不新增自由度**，而是把「规范遵守度」作为文化向量在规范方向上的投影：

```
ê_norm          预设的单位规范向量（模型外输入的"教化内容"，如礼义方向）
n_i  = max(0, c⃗_i · ê_norm)     个体 i 的规范遵守度（派生标量，∈ [0, |c⃗_i|]）
```

- 优点：复用现有 `c⃗` 数据布局与同化积分器，改动面最小；`n_i` 是观测量而非新状态，
  天然可解释为"该文化成分有多贴近教化内容"。
- 缺点：规范与知识在同一个向量里耦合，消融「教化=知识传播」与「教化=规范传播」需要
  借助投影方向来分离（可通过把 ê_norm 设为与"知识增长方向"正交的方向来隔离）。
- 备选方案 B：显式新增标量自由度 `n_i`，独立演化方程。更干净但违背"最少自由度"原则，
  且需改动 SoA 容器 `particle_data`、繁殖遗传、checkpoint 等全套设施。**仅在方案 A
  被证明无法分离"规范"与"知识"效应时才启用。**

### 3.3 教化者建模

引入一个**可配置的教化者集合**（初始少数 agent，或由初始条件标记），其行为规则：

```
对每个教化者 m（位置 x_m，规范方向 ê_norm）：
  对每个非教化者 i（在传播半径 R_jiaohua 内，或全局）：
    Δc⃗_i += α_j · w(‖x_i − x_m‖) · (ê_norm · ‖c⃗_i‖ − (c⃗_i·ê_norm)·ê_norm 方向分量修正) · dt
```

更简洁地：把 `c⃗_i` 向 ê_norm 方向做**非对称牵引**（只增强规范分量，不衰减其他分量）：

```
Δc⃗_i += α_j · w(r) · (ê_norm − proj_{ê_norm}(ĉ_i)) · dt
```

关键设计约束（对齐「对称规则、不对称结果」的涌现方法论）：

- 教化者的牵引力是**方向性、非对称**的，这是相对现有对称同化的本质差异；但这不是
  "预设结果"，而是把「存在一批传播规范的人」作为可配置的初始条件——正如现有框架允许
  配置初始 ε₀ 的区域差异（新月沃地 > 东亚）。
- 教化者自身也应消耗资源维持教学（`consumption` 加成），避免教化者成为零成本上帝之手。
- 必须提供**「哑教化者」反事实**：同样数量、同样资源、同样传播半径，但**传播方向随机**
  或无规范内容，以排除"教化者本身作为资源/权威中心"的混杂效应（见 §3.5）。

### 3.4 规范 → 行为的三条通道（均可独立开关）

| 通道 | 机制 | 现成接入点 | 新增参数（建议） |
|------|------|-----------|----------------|
| **合作成本下降** | 交换/生产中，规范遵守度高的对子摩擦更小 | `resource_exchange` 加 `(1 − κ_coop·(1−cos))` 因子 | `jiaohua_coop_strength` |
| **忠诚/秩序上升** | `evolve_loyalty` 加规范增益项，抵消文化惩罚 | 在 `culture_cost` 后加 `− η_norm·min(n_i,n_j)` | `jiaohua_loyalty_gain` |
| **文化统一加速** | 教化者牵引直接加速 Q → 1 | 新增教化者传播项（§3.3） | `jiaohua_rate`、`jiaohua_range` |

三者构成「教化」的三条可消融作用通道，对应 §1.3 的三个断言 A/B/C。

### 3.5 消融与对照实验设计

沿用 [research-proposal §9.6.4](../imports/politeia-ds/research-proposal.md) 的消融范式：

| 实验 | 条件 | 回答的问题 |
|------|------|-----------|
| J0 | 基线：有文化同化 + 忠诚 + 层级，**无教化者** | 参照态：无教化时文明结构如何 |
| J1 | J0 + 教化者（规范方向） | 教化是否改变 C/H/Q/叛乱率（主效应） |
| J2 | J1 但**哑教化者**（随机方向） | 排除教化者资源/权威混杂 |
| J3 | J1 仅开合作通道 | 断言 A：教化是否通过经济效率起作用 |
| J4 | J1 仅开忠诚通道 | 断言 B：教化是否通过秩序稳定起作用 |
| J5 | J1 仅开文化统一通道 | 断言 C：教化是否通过文化趋同起作用 |
| J6 | J1 但教化内容 = 纯知识（方向与知识增长同向） | 区分「规范教化」vs「知识教育」 |

每个实验 ≥ 5 个随机种子，比较稳态序参量 (C, H, Q, ⟨L⟩, 叛乱率, Gini) 及实体寿命分布。

### 3.6 观测量（复用现有分析模块）

- **主指标**：独立实体数 C、层级深度 H、政体类型分布（`detect_polities`）、实体寿命分布
  （从 `repair_hierarchy_graph` 的断链/继位事件统计）。
- **共主指标**：文化序参量 Q、平均规范遵守度 ⟨n⟩、平均忠诚度 ⟨L⟩、叛乱率。
- **次要指标**：财富 Gini、文化关联长度（`compute_culture_correlation`）、总财富漂移。

## 四、与当前 Cycle 的关系与推进顺序

### 4.1 依赖关系

```mermaid
flowchart LR
  C1[Cycle 1 景观空间组织] --> C3[Cycle 3 交换核稳态修复]
  C3 --> J[教化方案 MVP]
  J --> JFull[完整教化方案]
```

- 本方案**依赖交换核稳态修复（候选 C）落地**：只有在无非平凡稳态的对照基线上，
  「教化改变稳态结构」才有可靠参照。当前交换核仍在极化修复中（见
  [exchange-kernel-design.md](../exchange-kernel-design.md)）。
- 本方案是**独立研究问题**，不与 Cycle 1/2/3 混算显著性，遵循「一次只探索一个方案」约定。

### 4.2 最小可行验证（MVP）

建议的 MVP 范围（把命题压缩到最小可证伪内核）：

- **地形**：`flat`（关闭地形力与生产通道，先隔离地理混杂）。
- **人口**：固定人口（关闭繁殖/死亡），避免人口总量成为中介变量——对齐 Cycle 1 的
  最小状态策略。
- **交换核**：稳态修复后的候选 C，固定 `k, η_d, η_n`。
- **文化**：`culture_dim` 保持 2（1 维知识方向 + 1 维规范方向，便于分离）。
- **忠诚 + 层级**：开启 `form_attachments` / `evolve_loyalty` / `detect_polities`。
- **教化者**：初始 1–3 名教化者，传播规范方向。

**MVP 成功判据**（任一不满足则暂停，不 tune 出期望结果）：

1. 数值校准通过：守恒、非负、dt 收敛、重复性（对齐 `preflight`/`E0` 五检查）。
2. J1 vs J0：主效应（C/H/Q/叛乱率）的 95% 区间排除零，且超过数值噪声校准的 SESOI。
3. J2（哑教化者）不产生 J1 的效应：证明效应来自「规范内容」而非「权威中心」。
4. 通道消融 J3–J5 能区分主效应来源，否则只报组合效应。

### 4.3 推进路线（若 MVP 通过）

1. 引入可变人口（繁殖/死亡），检验教化效应在开放系统下是否稳健。
2. 引入地形（`clustered` / `shuffled` 对照），检验地理是否放大/抑制教化效应
   （呼应"中国地形 + 儒家教化"的直觉）。
3. 区分「规范教化」vs「知识教育」（J6），回答教化的独特性。
4. 若效应稳健，才考虑与历史文明案例做生成性类比。

## 五、科学可行性边界（能声称 / 不能声称什么）

### 5.1 能声称的结论

- 「在模型 X 的机制下，方向性规范传播是否/如何改变文明结构的稳态」——**生成性/机制类比**结论。
- 「教化通过经济效率 / 秩序稳定 / 文化统一中的哪条通道起作用」——**通道分解**结论。
- 「规范化效应是否需要规范内容（而非纯粹权威/资源中心）」——**反事实**结论。

### 5.2 不能声称的结论

- ❌ 「孔子/孟子造成了中国统一 / 中国文明独特性」——历史因果需要反事实历史，模拟给不出。
- ❌ 「儒家是中华文明的最优/必要条件」——模型只检验充分性方向，且限于所建模的通道。
- ❌ 「教化可以替代地理、技术等其它机制」——除非在多机制联合消融中显式检验。

> 这与 [research/question.md](../question.md) 的「Cycle 1 证据边界」精神一致：
> 模拟回答"机制是否充分"，不回答"历史如何发生"。

### 5.3 可证伪判据

- 若 J1 相对 J0 在所有通道消融下均不改变 C/H/Q/叛乱率 → **否定假设**，结论是
  "在当前模型里，规范教化不足以单独改变文明结构"——这本身是有科学价值的负结果。
- 若 J2（哑教化者）产生与 J1 相同的效应 → 效应是权威/资源混杂，不是规范内容 → 命题需重述。

## 六、技术 / 算力可行性

### 6.1 代码改动量（估算）

| 改动 | 位置 | 量级 |
|------|------|------|
| 新增教化者参数 | `config.hpp` / `config.cpp`（`jiaohua_*` 字段） | 小 |
| 教化者传播逻辑 | `interaction/culture_dynamics.cpp` 新增函数或分支 | 中 |
| 规范投影观测量 ⟨n⟩ | `analysis/order_params.cpp` | 小 |
| 行为通道调制 | `interaction/resource_exchange.cpp`、`interaction/loyalty.cpp` | 小 |
| 教化者初始条件标记 | `io/ic_loader.cpp` 或 config | 小 |
| 测试 | `tests/`（对齐 `test_exchange_kernel` 的单元测试范式） | 中 |

总体改动集中在 `interaction/`、`analysis/`、`config` 三个模块，不触碰核心积分器与并行框架。

### 6.2 算力与流程

- 算力需求与现有模块同阶（文化/忠诚都是 O(邻居对)，教化者传播若用全局则 O(n·m)，m≪n
  可忽略）。沿用 A100 服务器 `umi`，`jobctl` 幂等提交、`preflight`/`audit` 三 Gate 全部直接适用。
- 复现性：教化者初值、规范方向、传播半径均入 config 与 seed，符合 `experiment-reproducibility` 规则。

### 6.3 风险点（技术）

- 方案 A 中「规范」与「知识」在 `c⃗` 内耦合，需靠投影方向正交化来分离；若分离失败需回退方案 B。
- 教化者全局传播会引入非局域作用，需检查是否破坏 OpenMP 的 pair 遍历正确性（对齐
  exchange-kernel-design §4.1 的零和/可复现约束）。
- 新增「规范」语义可能触碰「涌现方法论」红线：必须证明教化效应是"从可配置初始条件
  涌现"，而非"在规则里预设了秩序结果"（见 §3.3 的哑教化者反事实）。

---

## 七、风险与应对

| # | 风险 | 应对 |
|---|------|------|
| 1 | 「教化」只是「文化同化」的重命名，无新增科学内容 | 用 J6（规范 vs 知识）与哑教化者反事实显式检验独特性 |
| 2 | 预设偏差：规则里内置了"教化→秩序"的因果 | 通道可独立关闭 + 哑教化者反事实 + 预注册 SESOI |
| 3 | 规范维度耦合难以分离 | 优先方案 A 投影，失败回退方案 B（显式自由度） |
| 4 | 交换核稳态未修复，对照基线不可靠 | 本方案排在 Cycle 3 稳态落地之后，不超前 |
| 5 | 全局教化者破坏并行/零和 | 教化传播走只读广播路径，不参与财富守恒对 |
| 6 | 命题太宽（历史因果） | 收缩到 §1.2 的机制命题，明确 §5 证据边界 |

## 八、结论

| 维度 | 评级 | 说明 |
|------|------|------|
| 科学可行性 | ★★★★☆ | 命题可收缩为可证伪机制问题，但只能给生成性结论 |
| 技术可行性 | ★★★★★ | 复用度高，改动集中在 interaction/analysis/config，算力同阶 |
| 与当前研究的关系 | 独立 | 依赖 Cycle 3 稳态修复，需作为后续候选方案排队 |
| 优先级建议 | 中 | 先跑 MVP（§4.2），用最小代价检验核心命题后再扩展 |

**建议**：在交换核稳态修复（Cycle 3）落地后，以 §4.2 的 MVP 为第一站——固定人口、
flat 地形、稳态交换核、最小文化/忠诚集 + 教化者，回答一个单一问题：

> 「方向性规范传播能否在匹配条件下改变文明的政治实体数、层级深度与文化统一度？」

若 MVP 通过，再沿 §4.3 逐步开放人口、地形与「规范 vs 知识」对照，最终形成一篇以
「教化作为文明凝聚机制」为主题的研究。若 MVP 不通过，该负结果同样具备发表价值——
它将说明：在当前这一类 Langevin 社会动力学模型中，规范教化**不足以**单独塑造文明结构。
