# v15 设计笔记：帝国形成的多路径机制

> **状态**: 设计阶段 (pending v14b 完整结果)
> **目标**: 解决 v14b "层级深但帝国小" 的问题

---

## 一、v14b 诊断

v14b 的继承修复使层级稳定 (H=28, loyalty decay 缓慢)，但帝国规模仅 7K。
对比历史:
- v12b = "蒙古模式": 快速征服 → 大帝国 (40K) → 快速崩溃
- v14b = "稳定封建": 深层级 → 持久但不扩张 → 小型领地

缺失的机制: **和平扩张路径**（征服不是帝国形成的唯一方式）

## 二、历史中帝国形成的路径

1. **军事征服** (v12-v14 已实现): A 攻击 B，B 臣服
2. **威望吸引** (待实现): 强大且富裕的政体自然吸引邻近小政体自愿依附
3. **联姻/联盟** (待实现): 两个独立政体通过领导者关系合并
4. **朝贡体系** (待实现): 弱者向强者纳贡以换取保护，不完全丧失独立性
5. **文化同化** (部分实现): 相同文化的政体更容易合并

## 三、v15 候选机制: 威望吸引 (Prestige Attraction)

### 概念

当一个政体明显强于邻近的独立个体或小政体时，这些弱者应该有**主动依附**的倾向，
而不仅仅等待被征服。

### 数学表达

对于独立个体 j (superior == -1)，邻域内存在政体领导者 i:

```
P_voluntary_attach = α_prestige × (power_i / power_j) × culture_similarity(i, j) × dt
```

条件:
- power_i > power_j × prestige_threshold (i 的实力是 j 的数倍)
- culture_distance(i, j) < max_culture_distance (文化足够接近)
- j 当前没有 superior

### 效果预期

- 强大的政体通过"引力"吸引周围散粒子，无需逐一征服
- 文化相似的政体更容易聚合（Q 的提高也促进了帝国形成）
- 帝国规模不再仅仅受征服速率限制

### 参数

```
prestige_attraction_rate = 0.01   # 基础吸引概率
prestige_threshold = 5.0          # 需要5x power差距才触发
prestige_culture_max = 0.3        # 文化距离上限
prestige_loyalty_init = 0.7       # 自愿依附的初始忠诚度（高于征服）
```

## 四、v15 候选机制: 政体合并 (Polity Merger)

### 概念

当两个独立政体的领导者相邻且文化接近时，较弱的一方可能接受较强者的领导。

### 数学表达

对于两个根节点 (superior==-1) 的领导者 i, j 且 power_i > power_j:

```
P_merger = α_merger × (power_i / (power_i + power_j)) × (1 - culture_distance(i,j)) × dt
```

合并后: j 的 superior 设为 i，j 的所有下属保持不变（整棵子树移植）。

### 效果

- 帝国可以通过吞并其他政体的**整棵层级树**来快速增长
- 不需要逐个征服每个成员
- 这更符合历史中的"受降"和"归顺"

## 五、实现优先级

1. **v15a**: 先实现 prestige_attraction（影响散粒子，最简单）
2. **v15b**: 再实现 polity_merger（影响政体间关系，更复杂）
3. **v15c**: 如果需要，添加朝贡体系
