## 二、核心发现：地形是政体形成的决定性变量

### 2.1 三大地形对比 @ step 100（10000步）

| 指标 | **Continent** | **Europe** | **China** | 排序 |
|------|:--:|:--:|:--:|------|
| 总人口 N | **31283** | 16045 | 16154 | C ≫ E ≈ Ch |
| 最大政体 | **983** | 707 | 485 | C > E > Ch |
| HHI (集中度) | 0.01119 | **0.01440** | 0.01136 | E > Ch ≈ C |
| 政权数 | 216 | 225 | 226 | 基本相同 |
| 酋邦数 | **142** | 105 | 113 | C > Ch > E |

### 2.2 四个决定性发现

#### 发现 1：人口容量因地形而异

```
Continent: 31283 人 / 10000 步 → ~250/500步增长
Europe:   16045 人 / 10000 步 →  ~97/500步增长
China:    16154 人 / 10000 步 →  ~94/500步增长
```

**Continent 的人口承载力是 Europe/China 的 2×**。这解释了为什么 M1.16 能产生 state：更多人 → 更多资源 → 更大政体。

#### 发现 2：破碎地形催生集中化

```
HHI (政治集中度):
Europe:  0.01440 — 最高
China:   0.01136 — 中等
Continent: 0.01119 — 与 China 相当
```

**Europe 的半岛/海湾**将人口分隔成高密度独立区域 → 每个区域 internal conquest 高效 → 少数大政体快速增长。

**China 的均匀大陆**→ 人口扩散 → 均匀的政体分布。

#### 发现 3：政体合并速度与破碎度正相关

```
政权数缩减 (2500→10000):
Europe:  392→225 (↓42.6%) — 最快合并
China:   343→226 (↓34.1%) — 中等
Continent: 249→216 (↓13.3%) — 最慢合并
```

Europe 虽然起步碎片更多，但合得最快。Continent 始终是最"稳定"的：政权数变化最小。

#### 发现 4：原始假说被彻底推翻

```
原假说: "China 封闭地形 → 更大政体"  ❌
实验结果: Continent → 最大政体 (983)
          Europe → 次大政体 (707)
          China → 最小政体 (485)
```

**修正假说**：政体规模由 `人口承载力 × 空间破碎度` 决定。
