# 基于 Langevin 动力学的人类文明演化模拟

> **导航**：[[DEVELOPMENT_PLAN]] · [[CODE_GUIDE]] · [[docs/parallel-framework-design]] · [[docs/stochastic-distributions]]

## 一、核心思想

用 Langevin 动力学框架模拟人类社会活动：将每个人抽象为一个"粒子"，在真实世界地形构成的势能面上，受确定性力、耗散力和随机力的共同驱动而演化。每个个体拥有多个连续自由度（财富、文化、能量利用能力），通过个体间的局部交互，观察群体聚集、层级结构、政治制度等宏观社会现象的自发涌现。

### 核心映射

| 分子动力学概念 | 社会映射 | 说明 |
|---|---|---|
| 粒子 | 个体人类 | 每个 agent 代表一个人 |
| 位置与速度 | 地理位置 + 移动能力 | 结合真实 DEM 地形数据 |
| 势能函数 | 地形、资源分布、人际吸引/排斥 | 核心难点：如何定义合理的势函数 |
| 动能 | 个体活力/生产力 | 受能量利用能力 ε 调制 |
| 能量守恒 | 交换中的守恒量（财富/资源） | 经济物理学已验证此假设的有效性 |
| 温度 T | 社会"活跃度"/时代动荡程度 | 控制随机涨落的强度，可随时间和区域变化 |
| 摩擦力 −γv | 制度腐化、知识遗忘、资源消耗 | 耗散项，使系统不可逆 |
| 随机力 ξ(t) | 日常随机事件、生老病死 | 高斯白噪声，微观社会事件的涨落效应 |
| Poisson 跳跃 | 技术突破、个体命运大事件 | 非连续的跃迁（ε 突破、暴富/破产、意外死亡） |
| 相变 | 社会制度突变（革命/统一） | 最有价值的观测目标 |
| 凝聚/成核 | 个体自发聚集为部落、城邦、国家 | 涌现行为的核心 |

## 二、Agent 定义：个体人类模型

### 2.1 自由度的哲学推导

定义自由度之前，需要从第一性原理回答一个根本问题：**人的哪些属性是真正独立的、不可互相推导的？**

#### 人与分子的本质区别

人是一个**开放耗散系统**——不断从环境中摄入能量，维持自身有序结构（对抗熵增），并在死亡时回归无序。这与分子有根本区别：

- 分子碰撞后分开，不留记忆。**人交互后，双方都被改变。**
- 分子的性质不会改变。**人的内部状态在持续演化。**
- 分子不需要外部能量输入就能存在。**人必须持续消耗能量，否则死亡。**

#### 哲学传统中的人性约化

**亚里士多德**——人是"政治动物"（zoon politikon），人的本质在于社会关系。

**马克思**——人的本质是一切社会关系的总和。人由生产力（能做什么）和生产关系（与他人的关系）定义。

**荀子**——"人之所以为人者，非特以二足而无毛也，以其有辨也。"人之所以为人，在于能区分（是非、亲疏、贵贱）——即认知和分类能力。

**中国传统**——人处于天地之间：
- **天**：自然法则、命运、随机性 → 对应模型中的随机力 ξ(t) 和 Poisson 跳跃
- **地**：资源、地理、物质条件 → 对应地形势能面 V(x)
- **人**：在天地之间，通过**德**（能力/品质）驾驭自然 → 对应内部自由度

#### 两个根本维度之间的张力

人的存在可以约化为两个根本维度：

```
物质维度  ←→  信息维度
```

- **物质维度**：人在哪里（空间），拥有多少资源（能量/物质存量）
- **信息维度**：人知道什么（知识），认同什么（文化归属）

连接这两个维度的桥梁是 **ε——能量利用能力**：

> *ε 将信息（知识）转化为物质能力（改造自然的力量）。这是人区别于其他动物的根本所在。*

#### 不可约自由度的独立性论证

| 候选自由度 | 能否被其他变量推导？ | 判定 |
|---|---|---|
| x_i（位置） | 不能 | **独立自由度** |
| p_i（动量） | 不能（与 x 共轭） | **独立自由度** |
| w_i（财富） | 不能：穷人可以有知识 | **独立自由度** |
| c⃗_i（文化） | 不能：同等财富的人文化可以不同 | **独立自由度** |
| ε_i（能量利用） | 不能：知道 ≠ 能做到 | **独立自由度** |
| s_i（武力） | 能：s ≈ f(w, ε)，技术和资源决定战斗力 | **派生量** |
| λ_i（寿命） | 能：λ ≈ h(w, ε)，财富和医疗技术决定寿命 | **派生量** |
| h_i（健康） | 通常能：h ≈ g(w, a, ε, ξ) | **派生量**（瘟疫时临时激活） |
| a_i（年龄） | 确定性演化 da/dt = 1，不受力 | **参数** |
| g_i（性别） | 出生时确定 dg/dt = 0，不受力，但调制繁殖角色 | **参数** |

### 2.2 个体状态向量

每个 agent 代表一个人。第 i 个个体在时刻 t 的完整状态为：

```
Z_i(t) = (x_i, p_i, w_i, c⃗_i, ε_i)
```

| 符号 | 含义 | 哲学根基 | 物理类比 |
|---|---|---|---|
| x_i | 地理位置（二维） | 物质存在 | 粒子位置 |
| p_i | 动量（二维） | 物质存在 | 粒子动量 |
| w_i | 财富/资源存量 | 生存需求（马斯洛第一层） | 势能（可释放的存量） |
| c⃗_i | 文化向量（d 维） | 认知+认同（荀子的"辨"） | 内部自旋/取向 |
| ε_i | 能量利用能力 | 驾驭自然（人之为人的本质） | 耦合常数 |

四个内部自由度对应人的四个不可约维度：**在（x）、有（w）、知（c⃗）、能（ε）**。

#### 文化向量 c⃗_i 的设计

c⃗_i 是向量而非标量，这是关键的设计决策。它同时承载两层不可分割的含义：

- **模 |c⃗_i|**：知识量——影响 ε 的跃迁概率、技术改良速率
- **方向 ĉ_i**：文化取向——定义群体认同（"我们"vs"他们"）

两个人的文化距离 |c⃗_i − c⃗_j| 决定合作倾向 vs 排斥倾向：
- 距离小 → 高合作概率（同一文化圈）
- 距离大 → 高冲突概率（文明冲突）

这使得**文化边界**和**群体认同**可以从动力学中自然涌现，而不需要预设离散标签。

### 2.3 参数、派生量与约束

#### 年龄 a_i（参数）

年龄不是自由度——它确定性演化（da/dt = 1），不受任何力驱动，不参与 Lagrangian。但它是关键参数，调制其他所有自由度的动力学：

```
生产力:     w_eff(a) = w · bell_curve(a)          （壮年最强）
生育能力:   φ(a) 为钟形曲线，仅在 [a_puberty, a_menopause] 内非零
学习能力:   d|c⃗|/dt 的系数随 a 先增后减
死亡概率:   P_death(a) 按 Gompertz 法则指数增长
```

#### 性别 g_i（参数）

性别与年龄类似——不是自由度，而是出生时确定、终身不变的参数。但它是模型中唯一的**生物学非对称性来源**，对繁殖动力学和社会结构有深远影响。

```
g_i ∈ {0, 1}        （0=女性, 1=男性，出生时以 sex_ratio 概率赋值）
dg_i/dt = 0          （不变）
```

性别引入的非对称性全部来自**生物事实**，而非模型偏袒：

| 属性 | 女性 (g=0) | 男性 (g=1) | 非对称的来源 |
|---|---|---|---|
| 妊娠冷却期 | T_gest + T_nurse ≈ 2-4 年 | T_male_cool ≈ 极短（可配置） | 妊娠和哺乳是生物事实 |
| 生育窗口 | [a_puberty, a_menopause] | [a_puberty, a_max] | 女性绝经是生物事实 |
| 每次生育代价 | 高（体力+资源） | 低 | 妊娠负担不对称 |
| 理论最大后代数 | ~15-20（受冷却期限制） | 无上限（仅受配偶数限制） | 冷却期非对称 |

##### 仅凭这一条非对称规则，婚配制度可以自然涌现

```
初始状态（所有人贫穷、ε 低）：
  男女都只够养活一个家庭 → w < 2×w_birth → 事实上的一夫一妻
  
财富分化后：
  富有男性（w 高 + 无冷却期）→ 可与多个女性繁殖
    → 事实上的一夫多妻自发涌现
  贫穷男性 → w < w_birth → 无法繁殖 → 被自然选择淘汰

权力集中后（Power_i 极高的首领/帝王）：
  → 吸引/征服更多人口 → 更多潜在配偶
  → 极端多妻（后宫制度）自发涌现
```

整个过程不需要预设"某种社会形态下应该一夫多妻"——它从生物非对称 + 财富分化 + 权力集中中自然生长出来。

##### 性别是否应该可关闭

性别参数应提供开关（`gender.enabled`）。关闭时退回当前行为（无性别区分，所有粒子对称），用于对照实验：**性别非对称性对文明演化的独立贡献有多大？**

#### 武力 s_i（派生量）

武力不是独立自由度。从哲学和历史两方面论证：

- **霍布斯**：在自然状态下人人大致平等，个体体力差异不是文明的决定因素
- **历史证据**：青铜器 vs 石器、枪炮 vs 弓箭——技术差距远超个体体力差距
- **中国传统**："士农工商"无独立的"兵"——士兵是农民拿起了武器

因此武力由财富和技术推导：

```
s_i = f(w_i, ε_i) = s₀ · w_i^α · ε_i^β
```

#### 有效寿命 λ_i（派生量，自然涌现）

寿命不是独立自由度——它可以从财富和技术水平推导：

- **个体层面**：富人能负担更好的营养、居住和安全条件，寿命更长（古代贵族平均寿命远超平民）
- **群体层面**：技术进步（尤其是医疗技术 ε）提升整个群体的预期寿命（人均寿命从古代 ~35 岁到现代 ~80 岁）

因此有效寿命由财富和技术推导：

```
λ_i = h(w_i, ε_local)
```

##### (1) 涌现优先原则

寿命的历史演化（从原始社会的 ~35 岁到现代的 ~80 岁）**不应由模型预设，而应从初始条件和耦合规则中自然涌现**。

我们只在配置文件中设定两类量：

```
可配置的初始条件（对应原始社会状态）：
  a_base = 50    基础自然寿命上限（低资源、无医疗时）
  β₀ = 0.12      原始状态衰老加速系数
  → 模拟初期：平均死亡年龄 ≈ 35，最长寿命 ≈ 50

可配置的耦合规则（w 和 ε 如何修正衰老）：
  k_w, α_w       财富-寿命耦合强度
  k_ε, α_ε       技术-寿命耦合强度
```

模型**不设定**"现代人寿命应该是 80 岁"——如果模拟在高 ε 状态下自然涌现出 ⟨寿命⟩ ≈ 75-80，那就是对耦合规则正确性的验证。如果涌现的值偏离历史数据，则需调整耦合系数——这与用已知历史规律做反演校准的总体方法论一致。

##### (2) Gompertz 参数的个体化

Gompertz 衰老模型的参数从全局常数变为个体函数：

```
有效最大年龄:
  a_max(i) = a_base + Δa_w(w_i) + Δa_ε(ε_local)
  
  a_base = 50                          基础自然寿命（可配置初始值）
  Δa_w   = k_w · min(w_i / w_ref, 1)  财富效应（有上限，营养/安全的边际递减）
  Δa_ε   = k_ε · log(1 + ε_local/ε_ref)  技术效应（对数增长，医疗革命的长期红利）

有效衰老加速:
  β_eff(i) = β₀ / (1 + α_w · w_i/w_ref + α_ε · ε_local/ε_ref)
  
  β₀ = 0.12                           原始状态下的快速衰老（可配置初始值）
  高 w → β 降低 → 衰老减缓            富人衰老更慢
  高 ε → β 降低 → 整体寿命延长        医疗进步惠及所有人
```

##### (3) 涌现的寿命演化轨迹

随着模拟中 ε 经历 Poisson 跳跃、w 分化加剧，寿命**自动**经历以下演化：

```
模拟初期（ε ≈ 1.0，w 均匀）：
  所有人:  a_max ≈ 50,  β ≈ 0.12  → 平均死亡年龄 ≈ 35

ε 跃迁 1（农业革命）→ ε ≈ 2：
  穷人:    a_max ≈ 55,  β ≈ 0.09  → 平均 ≈ 40
  富人:    a_max ≈ 65,  β ≈ 0.07  → 平均 ≈ 55（寿命差距开始拉大）

ε 跃迁 2（工业/医疗革命）→ ε ≈ 5：
  穷人:    a_max ≈ 65,  β ≈ 0.06  → 平均 ≈ 60
  富人:    a_max ≈ 85,  β ≈ 0.04  → 平均 ≈ 75（寿命差距继续扩大）

以上数值不是预设的，而是涌现的——
取决于 ε 何时跃迁、w 如何分化、耦合系数如何设定。
```

##### (4) 寿命作为涌现观测量

寿命延长的演化轨迹应该像 Gini 系数和层级深度一样被追踪为序参量：

| 观测量 | 符号 | 含义 | 历史验证数据 |
|---|---|---|---|
| 平均死亡年龄 | ⟨a_death⟩(t) | 文明整体健康水平 | 历史人口学数据 |
| 最大死亡年龄 | max(a_death)(t) | 医疗/财富上限效应 | 历史长寿者记录 |
| 寿命 Gini | G_life(t) | 寿命不平等程度 | 各时代阶层寿命差异 |
| 阶层寿命比 | ⟨a_death⟩_rich / ⟨a_death⟩_poor | 阶级在生死上的不平等 | 贵族 vs 平民寿命对比 |

这些观测量具有极好的可验证性——人口学家已经积累了大量的历史寿命分层数据，为模型校准提供了坚实基础。

##### (5) 寿命的正反馈与阶级固化

寿命作为派生量引入了一个重要的正反馈回路：

```
富裕 → 活得更久 → 更长的积累时间 → 更富裕 → ...
贫穷 → 早死 → 无法积累 → 后代仍然贫穷 → ...
```

这是历史上阶级固化的核心机制之一。同时寿命与 ε 演化耦合：

```
ε 跃迁（如医疗革命）→ 所有人寿命提升
  → 但富人受益更大（能负担新医疗技术）
  → 寿命差距可能先缩小再扩大（库兹涅茨曲线效应）
```

##### (6) 寿命与不可约自由度的独立性验证

| 测试 | 结果 |
|---|---|
| 寿命能否从 w 推导？ | 能：穷人短命、富人长寿 |
| 寿命能否从 ε 推导？ | 能：古代短命、现代长寿 |
| 同等 w 和 ε 下寿命是否仍有差异？ | 有，但由随机性（ξ）和年龄（a）决定，非独立自由度 |
| 判定 | **派生量**：λ_i = h(w_i, ε_local)，不是新自由度 |

#### 健康与免疫（派生量 / 瘟疫事件模块）

常规状态下，健康由其他变量推导：h ≈ g(w, a, ε, ξ)。死亡机制通过 w_i 的生存阈值和年龄参数处理。

**瘟疫差异化打击模型**：不同群体对同一种瘟疫的免疫力不同——这在历史上是极其关键的机制，多次改变了文明的走向。

##### (1) 免疫记忆向量 d⃗_i

每个个体携带一个**免疫记忆向量** d⃗_i（附属属性，非自由度）：

```
d⃗_i = (d¹_i, d²_i, ..., dᵐ_i)    dᵏ_i ∈ [0, 1]
```

dᵏ_i = 1 表示对第 k 种病原体完全免疫，= 0 表示无免疫力。

##### (2) 免疫的获取与传递

- **个体感染存活**：感染第 k 种病后存活 → dᵏ_i 升至 1
- **代际遗传**：dᵏ_child ≈ α · (dᵏ_mother + dᵏ_father)/2（部分继承，新生代需自身感染才能获得完全免疫）
- **群体免疫效应**：同一聚落中多数人免疫时，未免疫个体的感染概率降低（群体屏障）

##### (3) 群体规模与病原体多样性

大群体能维持更多病原体的地方性流行（endemic），从而积累更广的免疫谱：

```
群体有效病原体数 m_eff ∝ log(N_group)
```

- 大型定居文明（欧亚大陆）：高人口密度 + 畜牧业（人畜共患病）→ 免疫谱广（天花、麻疹、流感、鼠疫…）
- 小型狩猎采集群体（美洲、澳洲、太平洋岛屿）：低人口密度 + 少畜牧 → 免疫谱窄

这意味着**文明发展程度（ε 和人口规模）本身就决定了免疫谱的宽度**——强文明不仅有更好的武器，还携带更多的病原体。

##### (4) 瘟疫触发与 SIR 传播动力学

瘟疫事件通过两种方式触发：

**方式一：内生触发**（Poisson 过程）
```
在人口密度 ρ(x) > ρ_threshold 的区域，以速率 λ_plague 随机生成新病原体 k
```
高密度聚居区（城市）更容易爆发瘟疫——这与历史一致。

**方式二：接触触发**（跨群体传播）
```
当群体 A 的个体与群体 B 的个体接触时：
  对群体 A 携带的每种病原体 k：
    若 A 成员的平均 dᵏ > 0.8 且 B 成员的平均 dᵏ < 0.2
    → 在群体 B 中触发病原体 k 的 SIR 传播
```

瘟疫触发后，在空间上按 SIR 动力学传播：

```
对受影响区域内的每个个体 i：
  状态转移: S(易感) → I(感染) → R(康复) 或 D(死亡)

  感染概率:  P_infect(i) = β × (附近 I 态个体数) / (附近总个体数)
  死亡概率:  P_death(i)  = P₀ × (1 − dᵏ_i) × (1 − ε_i/ε_med)
  康复概率:  P_recover(i) = 1 − P_death(i)
  康复后:    dᵏ_i → 1（获得免疫）
```

其中 ε_i/ε_med 项反映了**医疗技术**——高 ε 群体即使没有先天免疫，也有更高的存活率。

##### (5) 接触传播与免疫差异：核心机制

```
群体 A（大陆文明，长期有病原体 k 流行，dᵏ ≈ 1）
  ↓ ε 跃迁使航海/越境成为可能
  ↓ 越过地形势垒（海洋/山脉）接触
群体 B（被势垒长期隔离，从未接触病原体 k，dᵏ ≈ 0）
  → 群体 B 遭受毁灭性打击（死亡率可达 30-90%）
  → 人口崩溃 → 资源被群体 A 占据 → 文明格局重组
```

##### (6) 与模型核心要素的耦合

| 模型要素 | 与瘟疫差异化的关系 |
|---|---|
| **地形势垒** | 势垒越高 → 隔离越久 → 免疫差异越大 → 接触时冲击越强 |
| **ε 跃迁** | 航海技术突破 → 跨越海洋势垒 → 触发跨大陆瘟疫传播 |
| **文化向量 c⃗** | c⃗ 距离大的群体 → 历史上交流少 → 免疫谱差异大 |
| **群体规模 N** | 大群体维持更多地方性病原体 → 接触小群体时是"瘟疫输出方" |
| **ε 水平** | 高 ε → 更好的医疗 → 感染后存活率更高 |
| **人口密度 ρ** | 高密度 → 更易爆发内生瘟疫 → 但也更快获得群体免疫 |

##### (7) 瘟疫后的社会重组：非平衡态淬火

瘟疫对社会结构的影响不仅是"杀人"，更是**改变系统的相**。类似于物理中的非平衡态淬火——系统被突然扰动到远离平衡的状态，然后弛豫到**新的平衡**：

```
瘟疫前:  人口 N₀，制度处于相 A（如封建制）
  ↓ 瘟疫杀死 30-50% 人口
瘟疫后:  人口 N₁ << N₀
  → 劳动力稀缺 → w_i 上升（劳动者议价能力增强）
  → 层级关系松动 → superior_i 指针断裂
  → 系统弛豫到新的相 B（如自由市民制）
```

历史验证：
- **黑死病 (1347-1351)**：欧洲人口减少 30-60% → 劳动力稀缺 → 农奴制崩溃 → 推动文艺复兴和资本主义萌芽
- **哥伦布交换 (1492 后)**：天花等疾病杀死美洲 90% 原住民 → 欧洲人占据空出的生态位 → 全球殖民体系形成
- **安东尼瘟疫 (165-180)**：罗马帝国人口减少 → 军事力量衰退 → 加速帝国衰落

如果模型能自发地在以下条件下涌现出类似模式，将是强有力的验证：
1. 旧大陆（欧亚非）群体因大陆连通性好、人口密集 → 免疫谱广
2. 新大陆（美洲、澳洲）群体因被海洋势垒隔离 → 免疫谱窄
3. 当 ε 跃迁使航海成为可能 → 接触 → 免疫谱窄的一方人口灾难
4. 人口灾难后 → 资源被免疫方占据 → 文明格局重组

#### 群体归属与层级关系（涌现拓扑，非自由度）

群体归属不是个体的内在属性，而是**交互的涌现结果**：

1. **文化相似性**：c⃗_i ≈ c⃗_j → "我们是同一类人"（由文化向量处理）
2. **依附关系**：当不对称交互产生层级后，个体通过依附链连接到中心节点

每个粒子维护一个**依附指针** superior_i 和对应的**忠诚度权重** L_ij。

#### 权力：为什么不是自由度

权力（power）不应作为个体的独立自由度，原因有三：

1. **权力是关系属性，不是个体属性**。皇帝的权力存在于"其他人服从他"这个事实中，而非皇帝的身体或头脑里。物理类比：权力类似于压强——它不是单个分子的属性，而是集体行为的涌现量。
2. **加入 DOF 会循环定义**。power_i 高 → 别人服从 → 子树大 → power_i 高，这不是独立变量。
3. **权力的转移不依赖个人属性变化**。秦二世继位时 w, c⃗, ε 都没变，但突然"有了"权力——权力是**位置属性**，不是个体属性。

#### 忠诚度 L_ij：依附边的权重

真正需要加入的不是个体的"权力自由度"，而是依附关系的**强度/稳定性**——**忠诚度 L_ij**。

```
L_ij ∈ [0, 1]    （个体 i 对其上级 j 的忠诚度/合法性认同）
```

```
L_ij ≈ 1 → 高度忠诚（"君要臣死，臣不得不死"）
L_ij ≈ 0 → 即将叛变（"王侯将相宁有种乎"）
```

##### L_ij 的演化方程

```
dL_ij/dt = [受益项] − [剥削项] − [文化距离项] + η(t)
```

| 驱动项 | 公式形式 | 含义 |
|---|---|---|
| 受益项 (+) | +α · protection(j→i) | 上级保护/分配资源 → 忠诚增加 |
| 剥削项 (−) | −β · tax_rate(j→i) | 上级过度征税/剥削 → 忠诚降低 |
| 文化距离 (−) | −γ · \|c⃗_i − c⃗_j\| | 异族/异文化统治 → 忠诚天然更低 |
| 噪声 | +η(t) | 随机事件影响忠诚（如主帅阵亡导致军心动摇） |

##### 忠诚度触发的事件

```
L_ij < L_rebel    → 叛乱：superior_i 断裂，i 成为独立根节点
L_ij < L_switch   → 投靠：superior_i 转移到另一个更有利的上级
L_ij 群体性崩塌    → 王朝覆灭：所有人同时断开指针，系统重新组织
```

##### 文化距离对忠诚度的影响

文化向量 c⃗ 距离大的依附关系天然不稳定。这解释了历史上的核心规律：

- 同文化统治更稳定（如秦统一中国后的文化统一政策）
- 异族征服王朝寿命通常更短（如元朝 98 年 vs 明朝 276 年）
- 宗教/文化同化是维持帝国的关键手段（如罗马的公民权扩展）

#### 有效权力 Power_i（派生量）

权力作为**派生量**从依附拓扑 + 忠诚度计算：

```
Power_i = Σ_{j ∈ subtree(i)} w_j × L_path(i, j)
```

其中 L_path(i, j) 是从 j 到 i 的依附链上所有忠诚度的乘积：

```
L_path(i, j) = L_{j,k₁} × L_{k₁,k₂} × ... × L_{kₙ,i}
```

含义：
- 子树大（管辖人多）→ 权力大
- 链上忠诚度高 → 权力有效
- 链上任何一环 L ≈ 0 → 那个分支的资源调动不了（"将在外，君命有所不受"）

有效权力 Power_i 参与以下交互：
- 征服：Power_i > Power_j → i 可能征服 j，j 的 superior 指向 i
- 威慑：Power_i 大 → 周围个体更倾向于主动依附（而非被征服）
- 税收：i 可以从 subtree 中提取资源，提取量 ∝ Power_i

| 候选 | 判定 | 理由 |
|---|---|---|
| power_i 作为 DOF | **否** | 权力是关系属性，非个体属性；加入会循环定义 |
| L_ij 作为边权重 | **是** | 描述依附关系强度/稳定性，是独立的新信息 |
| Power_i 作为派生量 | **是** | 从子树 + 忠诚度计算，用于观测和交互 |

#### 生存阈值（硬约束）

```
每个时间步:  w_i -= consumption(a_i, ε_i)
地形产出:    dw_i/dt 包含 +R(x_i) × f(ε_i)
生存约束:    若 w_i < w_survival → P_death 急剧增加
             若 w_i ≤ 0 → 死亡
```

#### 个体命运的 Poisson 跳跃

Poisson 跳跃不应该只作用在 ε（技术突破）上，还应该作用在 w_i（财富）和死亡概率上。人的一生中，大多数时候平淡（高斯扩散），偶尔出现改变一切的大事件（跳跃）。

##### (1) 财富跳跃（运气/厄运）

```
dw_i = [漂移项 + 交互项] dt + ξ_w(t)dt + Δw · dN_w(t)
                                 ↑              ↑
                           日常小波动      稀有大事件
```

其中 Δw 可正可负，由两个独立的 Poisson 过程驱动：

```
正跳跃 Δw > 0（概率 λ+）：发现矿藏、意外继承、战利品、贸易暴利
负跳跃 Δw < 0（概率 λ-）：被抢劫、自然灾害摧毁财产、火灾、洪水
```

跳跃幅度 |Δw| 可以服从指数分布或幂律分布——小的意外多，大的意外少，但大意外的影响极其深远。

##### (2) 随机死亡（意外/厄运）

每个时间步，每个个体有一个**与年龄和财富无关**的基础死亡概率：

```
P_accident = λ_death · dt
```

这代表雷击、毒蛇咬伤、坠崖、溺水等纯粹的"命运"事件——无论你多富有、多年轻，都无法完全避免。

##### (3) 完整的个体死亡机制

一个人的死亡由**四个独立机制**触发，总死亡概率为：

```
P_death(i) = P_age(a_i) + P_starve(w_i) + P_accident + P_plague(事件期)
```

| 死亡机制 | 公式 | 含义 |
|---|---|---|
| 衰老 | P_age ~ exp(β_eff(w_i,ε)·a_i)，a_i > a_max(w_i,ε) 时必死 | 衰老速率受财富和技术调制 |
| 饥饿 | P_starve ~ 1/(1+exp(k·(w_i − w_threshold))) | 资源低于阈值时急剧增加 |
| 意外 | P_accident = λ_death（常数） | 纯随机，与年龄、财富无关 |
| 瘟疫 | P_plague = P₀×(1−dᵏ_i)×(1−ε_i/ε_med)（仅事件期） | 差异化传染性死亡 |

四重死亡机制使得人口动力学更加真实：
- 和平年代：主要由衰老和意外决定寿命
- 资源匮乏时：饥饿成为主要死因（如饥荒）
- 瘟疫事件期：传染病主导死亡率（如黑死病）
- 任何时候：意外死亡提供不可消除的基线死亡率

##### (4) Lévy-type Jump-Diffusion 的物理含义

加入财富跳跃和随机死亡后，模型的随机过程从纯 Langevin（高斯噪声）升级为**Lévy-type jump-diffusion**：

```
小而频繁的波动（高斯白噪声 ξ(t)）：日常生活的起伏
大而稀有的跳跃（Poisson 过程 dN(t)）：改变命运的关键事件
```

这在数学上对应**厚尾分布**——极端事件的概率比高斯分布预测的要高得多。这也解释了一个重要的经验事实：人类社会的财富分布不是高斯（正态）分布，而是 Pareto 幂律分布——正是这些"稀有大事件"的跳跃项产生了厚尾。

在模型中，三种 Poisson 跳跃各有不同的作用：

| Poisson 跳跃类型 | 作用对象 | 社会含义 | 影响范围 |
|---|---|---|---|
| ε 跳跃 | 能量利用能力 | 技术革命 | 个体发现 → 群体传播 → 文明相变 |
| w 跳跃 | 财富存量 | 个体运气/厄运 | 个体层面，驱动财富厚尾分布 |
| 死亡跳跃 | 生存状态 | 意外事故 | 个体层面，提供基线死亡率 |
| 瘟疫跳跃 | 群体生存 | 传染病爆发 | 群体层面，触发社会结构重组 |

### 2.4 能量利用能力 ε_i：文明演化的核心驱动力

> 深度分析：人 vs 动物的 ε 方程差异 → [[docs/why-humans-not-animals]]
> 代码实现 → [[CODE_GUIDE#5. `interaction/` — 个体间交互]]

人类文明史本质上是一部能量利用能力的升级史。理论基础：

- **Leslie White 能量-文化演化律 (1943)**：文化的发展程度与人均可利用的能量成正比
- **Kardashev 等级**：以能量利用量划分文明层次（I/II/III 型）
- **Vaclav Smil**：系统论述了能量转型与社会变革的关联

#### ε_i 作为乘性因子

ε_i 是一个乘性因子，放大其他所有自由度的效能：

```
实际生产力     ~ w_i × f(ε_i)
实际武力       ~ s₀ · w_i^α · ε_i^β
文化传播半径   ~ r₀ × h(ε_i)
局部人口承载力 ~ N₀ × ε_i
```

ε_i 修改了系统的有效耦合常数——能量利用能力越强，系统动力学特征发生质变。

#### ε_i 的演化方程

```
dε_i = [α·|c⃗_i|·ε_i] dt + [交互传播项] dt + Δε·dN_i(t)
```

三个演化机制：

**1. 缓慢积累（漂移项）**：drift = α · |c⃗_i| · ε_i（知识越多、技术越高，改良越快——马太效应）

**2. 交互传播（扩散项）**：低 ε 向高 ε 学习，受地形势垒阻隔

**3. 突变发现（Poisson 跳跃）**：跳跃项 = Δε · dN_i(t)，速率 λ(|c⃗_i|)（知识越多，突破概率越高）

#### ε 跃迁与社会相变的对应

| ε 等级跃迁 | 历史对应 | 社会结构变化 |
|---|---|---|
| ε₀ → ε₁ | 火的使用 | 游猎群体 → 定居部落 |
| ε₁ → ε₂ | 农业革命 | 部落 → 城邦/早期国家 |
| ε₂ → ε₃ | 冶铁/畜力 | 城邦 → 帝国（分封/郡县） |
| ε₃ → ε₄ | 煤炭/蒸汽机 | 农业帝国 → 工业国家 |
| ε₄ → ε₅ | 电力/石油/核能 | 民族国家 → 全球化体系 |

### 2.5 人口动力学：繁殖模型

> 代码实现 → [[CODE_GUIDE#6. `population/` — 人口动力学]]
> 生育/死亡分布详解 → [[docs/stochastic-distributions#3. 死亡机制]] · [[docs/stochastic-distributions#4. 生育]]

人口是文明的基底。繁殖模型需要捕捉人类生殖的核心生物学约束：性成熟年龄、妊娠期、生育能力随年龄的变化，以及资源对人口的马尔萨斯约束。

#### 2.5.1 生育能力曲线 φ(a)

每个个体有一个依赖年龄的生育能力函数：

```
φ(a_i) = 0                          当 a < a_puberty（性成熟前，~15岁）
φ(a_i) = φ_max · β(a; α₁, α₂)      当 a ∈ [a_puberty, a_menopause]
φ(a_i) = 0                          当 a > a_menopause（绝育期，~45岁）
```

β 为 Beta 分布形状的钟形曲线——性成熟后迅速上升，壮年达到峰值，之后逐渐下降：

```
     φ
     ↑     ╭───╮
     │    ╱     ╲
     │   ╱       ╲
     │  ╱         ╲
     │ ╱           ╲
     ├──┼─────┼──────┼──→ a
     0  a_pub  peak  a_meno
         15    25     45
```

#### 2.5.2 交配条件

两个个体要繁殖，需同时满足六个条件：

```
条件 1（空间接近）:  |x_i − x_j| < r_mate           必须在近距离
条件 2（性别互补）:  g_i ≠ g_j（启用性别时）          必须一男一女
条件 3（双方可育）:  φ(a_i, g_i) > 0 且 φ(a_j, g_j) > 0  都在生育年龄
条件 4（文化兼容）:  |c⃗_i − c⃗_j| < d_culture        文化距离不能太大
条件 5（资源充足）:  w_i > w_birth 且 w_j > w_birth   需要足够资源养育后代
条件 6（非孕期）:    t − t_last_birth(i) > T_cool(g_i)  冷却期已过（按性别区分）
```

条件 2 仅在 `gender.enabled = true` 时生效；关闭时退回当前对称模型。

条件 4（文化兼容）尤其有意义——文化隔离自然导致生殖隔离，长期下来不同文化圈的群体会进一步分化。这类似于生物学中的同域物种形成。

##### 多偶制的自然约束

当启用性别后，婚配制度不需要预设，但可以通过以下可配置参数加以约束或放松：

```
max_partners_per_cooldown = 0    （0=无限制，自然涌现婚配制度）
                           = 1    （强制一夫一妻：每个冷却周期内只能有一个伴侣）
                           = N    （有限多偶）

partner_wealth_factor = 1.0      （多偶时每增加一个配偶的额外财富门槛倍数）
  含义：第 k 个配偶需要 w > k × partner_wealth_factor × w_birth
  效果：只有足够富裕的个体才能"负担"多个配偶
```

当 `max_partners = 0` 且 `partner_wealth_factor > 0` 时，婚配制度完全由财富决定——穷人事实上一夫一妻，富人事实上一夫多妻。**这与历史上大多数前现代社会的真实状况一致。**

#### 2.5.3 妊娠与冷却期（性别非对称）

```
交配成功（设 i 为女性、j 为男性）
  
  女方 (g=0)：
    → 进入妊娠期 T_gest（~10个月）
        - 母体生产力降低：w_eff 打折
        - 母体移动能力降低：|p|_max 受限
        - 不可再次受孕
    → T_gest 后：新粒子在母体附近注入世界
    → 进入哺育期 T_nurse（~1-3年）
        - 母体需额外消耗资源
        - 不可再次受孕（自然避孕效应）
    → 女性总冷却期 T_cool_f = T_gest + T_nurse ≈ 2-4 年

  男方 (g=1)：
    → 男性冷却期 T_cool_m ≈ 0.1（极短，可配置）
    → 可在冷却期后与其他可育女性交配
    → 这是一夫多妻涌现的生物学基础
```

冷却期的非对称性是整个婚配制度涌现的根源。如果 T_cool_m 设为与 T_cool_f 相同，则事实上回到对称模型（一夫一妻倾向）。

#### 2.5.4 后代属性的遗传与变异

新粒子的初始状态：

```
x_child  = x_mother + δx                          母体附近出生
p_child  = 0                                      新生儿静止
g_child  ~ Bernoulli(sex_ratio)                    性别随机赋值
w_child  = w₀_birth                               固定初始资源（由父母提供）
c⃗_child = α_m · c⃗_mother + α_f · c⃗_father + η_c  按继承模式加权（见 §2.5.5）
ε_child  = max(ε_mother, ε_father) + η_ε           继承较高的技术水平 + 微小变异
a_child  = 0                                      年龄从零开始
d⃗_child = α·(d⃗_mother + d⃗_father)/2              部分继承父母免疫力
```

遗传规则的含义：
- **g 赋值**：性别随机，约 50:50 → 长期维持性别比平衡
- **c⃗ 遗传**：按继承模式加权 → 母系社会偏母、父系社会偏父（详见 §2.5.5）
- **ε 遗传**：取较高者 → 技术只会向上兼容，不会忘记父母已掌握的技术
- **w 传递**：父母资源被分出一部分 → w_mother -= w₀_birth, w_father -= w₀_birth
- **d⃗ 遗传**：部分继承 → 新生代免疫力低于父代，需要自身感染获得完全免疫

#### 2.5.5 继承方向：母系 vs 父系的涌现

人类社会从母系到父系的转变有清晰的物质基础解释：

| 社会形态 | ε 水平 | 经济基础 | 继承方向 | 原因 |
|---|---|---|---|---|
| 采集社会 | ε₀ | 女性采集贡献 ≥ 男性狩猎 | **母系** | 亲缘确定性 + 女性经济贡献高 |
| 早期农业 | ε₁-ε₂ | 男性体力劳动贡献增加 | **过渡期** | 私有财产开始积累 |
| 农业/畜牧 | ε₂-ε₃ | 男性控制土地/牲畜 | **父系** | 需确定继承人 + 男性经济主导 |
| 工业/现代 | ε₄-ε₅ | 性别经济差异缩小 | **双系/法定** | 法律取代习俗 |

模型提供三种可配置的继承模式：

**模式 1：按贡献比例（推荐，最大涌现）**

```
parent_weight_mother = w_m × ε_m / (w_m × ε_m + w_f × ε_f)
parent_weight_father = 1 − parent_weight_mother

c⃗_child = parent_weight_mother × c⃗_mother + parent_weight_father × c⃗_father + η_c
superior_child = (parent_weight_mother > parent_weight_father) ? sup_mother : sup_father
```

在这种模式下：
- 当女性采集贡献高（低 ε 社会）→ 自动偏向母系
- 当男性农业贡献高（高 ε 社会）→ 自动偏向父系
- **母系→父系的转变从 ε 跃迁中自然涌现，不需要预设阈值**

**模式 2：ε 阈值触发**

```
if ε_local < ε_patrilineal_threshold:
    α_m = 0.7, α_f = 0.3    → 母系主导
else:
    α_m = 0.3, α_f = 0.7    → 父系主导
```

更简单，但不如模式 1 涌现。适合快速实验。

**模式 3：强制固定**

```
inheritance_model = "matrilineal"   → 始终 α_m=0.7, α_f=0.3
inheritance_model = "patrilineal"   → 始终 α_m=0.3, α_f=0.7
inheritance_model = "equal"         → 始终 α_m=0.5, α_f=0.5（当前行为）
```

用于对照实验：测试不同继承制度对文明演化的独立影响。

#### 2.5.5 马尔萨斯反馈：资源对人口的约束

```
地形位置 x 的资源承载力:  K(x) = R(x) × f(ε_local) / consumption_per_capita
当前局部人口密度:          ρ(x) = 附近粒子数
```

当 ρ(x) 接近 K(x) 时：
- 人均资源减少 → w_i 下降 → 不满足 w_i > w_birth → 生育率降低
- 进一步拥挤 → w_i < w_survival → 死亡率升高
- 部分个体迁徙到低密度区 → 人口扩散

形成自然的负反馈环：

```
人口增长 → 资源紧张 → 生育降低 + 死亡升高 + 迁徙 → 人口稳定
                                                      ↓
                                              ε 跃迁 → K(x) 提高
                                                      ↓
                                              新一轮人口增长
```

每次 ε 跃迁（如农业革命）提高承载力 K(x)，释放新一轮人口增长空间——这与历史完全吻合。

#### 2.5.6 完整的人口动力学方程

```
个体出生率: B_i = φ(a_i) × Θ(w_i − w_birth) × Θ(t − t_last − T_cool) × P_mate(x_i)
个体死亡率: D_i = P_age(a_i) + P_starve(w_i) + P_accident + P_plague(event)
群体净增长: dN/dt = Σ B_i − Σ D_i
```

其中：
- φ(a_i)：年龄依赖的生育能力曲线
- Θ：Heaviside 阶跃函数（条件满足为 1，否则为 0）
- P_mate(x_i)：在位置 x_i 找到合适配偶的概率（取决于局部密度和文化兼容性）
- P_age：Gompertz 衰老死亡
- P_starve：饥饿死亡（w_i 低于阈值）
- P_accident：纯随机意外死亡（常数，与年龄、财富无关）
- P_plague：瘟疫死亡（仅事件期，依赖免疫向量 d⃗）

#### 2.5.7 繁殖与文明涌现的关联

| 繁殖机制 | 文明效应 |
|---|---|
| 文化兼容性条件 | 文化圈内通婚 → 文化趋同固化 → 文明边界强化 |
| 资源门槛 | 富裕地区人口更多 → 河谷文明人口优势 → 军事优势 |
| ε 继承 | 高技术群体的后代自动继承技术 → 技术领先固化 |
| 马尔萨斯反馈 | ε 跃迁打破承载力天花板 → 人口爆发 → 社会结构必须重组 |
| 冷却期 | 限制增长率 → 防止数值上的人口爆炸 |
| 免疫遗传 | 群体免疫谱跨代积累 → 大陆规模的免疫差异 → 接触时单方面灾难 |

### 2.6 涌现方法论：对称规则，不对称结果

#### 2.6.1 核心原则：不预设层级

宏观社会结构（阶级、层级、王朝、制度）必须**完全从对称的微观规则中自发涌现**，而非由模型预设。这是本项目的核心方法论约束。

**什么算"预设"（不允许）**：
- 在数据结构中预建 superior_i 指针（等于假设层级会出现）
- 写入"胜者更强"的显式规则（等于假设不平等会加剧）
- 预设忠诚度 L_ij 系统（等于假设臣服关系会存在）

**什么算"涌现"（目标）**：
- 只定义对称的、局部的微观交互规则
- 观察宏观上是否自发产生不对称的层级结构
- 如果不产生，那就是模型告诉我们的结论——同样有科学价值

#### 2.6.2 对称的资源交换规则

当两个个体 i 和 j 接触时，资源交换规则本身必须是对称的：

```
能力值:  A_i = w_i × f(ε_i)，A_j = w_j × f(ε_j)
交换量:  Δw = η × (A_i − A_j) / (A_i + A_j) × min(w_i, w_j)

Δw > 0 → 资源从 j 流向 i
Δw < 0 → 资源从 i 流向 j
```

这个规则在 i 和 j 的标签互换下是**完全对称的**——没有任何一方被偏袒。但由于 A_i ≠ A_j（个体状态不同），**结果是不对称的**——能力强的一方自然获益更多。

物理类比：引力定律 F = Gm₁m₂/r² 是完全对称的，但大质量体依然吸引更多物质，形成层级结构（行星围绕恒星）。不平等不是牛顿规定的，而是质量差异的自然结果。

#### 2.6.3 层级从无到有的涌现因果链

```
随机初始条件（所有人大致平等，微小差异来自涨落）
  ↓
对称规则下的不对称结果（能力高者在交换中获益更多）
  ↓
财富差距通过正反馈扩大（富者越富）                    ← 涌现
  ↓
空间上的资源流动形成稳定的方向（穷人向富人缴纳资源）   ← 涌现
  ↓
持续的单向资源流 ≡ 事实上的"纳贡"关系                ← 可观测的模式
  ↓
多层纳贡链 ≡ 层级结构                               ← 涌现！
  ↓
层级足够深 + 稳定 ≡ "王朝"                          ← 涌现！
```

每一步都是上一步的自然结果，没有任何一步需要预先规定"会有层级"。整个链条的驱动力仅仅是**对称规则 + 状态差异 + 正反馈**。

#### 2.6.4 层级的事后检测而非预先构建

不在模型中预建 superior_i 指针，而是从**交互模式**中事后检测层级：

```
定义"事实支配关系"：
  如果个体 i 在过去 T 个时间步中，
  从个体 j 持续获取资源（净流入 > 阈值），
  则标记一条事实支配边 i → j

这些支配边自然形成一个有向图：
  如果图中出现树状结构 → 层级涌现了
  如果图始终是均匀的   → 层级没有涌现
  两种结果都是有科学价值的发现
```

#### 2.6.5 分阶段引入层级机制

| 阶段 | 层级机制 | 目的 |
|---|---|---|
| 阶段 1-3 | **不含任何层级机制** | 验证层级是否能从对称规则中自发涌现 |
| | 无 superior_i、无 L_ij、无 Power_i | 只用交互网络分析事后检测层级 |
| | 只用对称交换规则 | 这是"涌现实验" |
| 阶段 4 | **引入 superior_i 和 L_ij** | 对已涌现的层级做精细化描述 |
| | 仅在层级被确认涌现后引入 | L_ij 描述关系强度，Power_i 描述有效权力 |
| | 此时引入是合理的，因为层级已被证明会涌现 | 这是"建模细化" |
| 阶段 5+ | **完整模型** | 含忠诚度演化、叛乱、世袭、税收等 |
| | 所有机制都基于已验证的涌现现象 | 这是"机制丰富化" |

这样可以自信地说：**"层级是涌现的，不是我放进去的。我只用了对称的物理规则，层级自然从状态差异和正反馈中生长出来。后续的忠诚度和权力机制只是对已涌现现象的精细化描述。"**

#### 2.6.6 涌现机制总结

**群体形成（凝聚/成核）**

LJ 势驱动空间聚集（对称规则）。文化向量的趋同固化群体边界。繁殖的文化兼容性条件强化文化圈封闭性。这些都是对称规则，群体是涌现的。

**不平等涌现（对称性破缺）**

对称的资源交换规则 + 初始状态的微小差异 → 通过正反馈自发放大为显著的财富不平等。物理类比：自发对称性破缺。

**层级涌现（如果发生）**

持续的不对称资源流动自然形成"事实上的纳贡链"。多层纳贡链构成树状层级。这是涌现的，不是预设的。能否涌现、以什么形态涌现，是模拟要回答的核心科学问题。

**制度涌现（相变，如果发生）**

当层级深度、群体规模、ε 水平同时满足特定条件时，系统可能进入不同的"相"——对应不同的政治制度形态。但制度是否真的会涌现、涌现出什么形态，**必须由模拟告诉我们，而非由我们告诉模拟**。

## 三、物理框架：Langevin-跳跃扩散社会动力学

> 代码实现 → [[CODE_GUIDE#4. `integrator/` — 时间积分]]
> 噪声与分布详解 → [[docs/stochastic-distributions#1. 运动方程 — Langevin 噪声]]

### 3.1 为什么选择 Langevin 动力学而非纯 Hamilton 力学

纯分子动力学（Hamilton 力学）假设能量守恒与时间可逆，但人类社会具有强烈的不可逆性和随机性。Langevin 动力学通过引入耗散项和随机力，天然地适应社会系统的特征。

**运动方程**：

```
m·q̈ = −∇V(q) − γ·q̇ + ξ(t) + J(t)
```

其中：
- −∇V(q)：确定性力（地形势、人际交互势）
- −γ·q̇：耗散力（制度腐化、知识遗忘）
- ξ(t)：高斯白噪声（日常随机事件）
- J(t)：Poisson 跳跃项（技术突破、个体命运大事件）

ξ(t) 满足涨落-耗散关系：

```
⟨ξ(t)·ξ(t')⟩ = 2γ·k_B·T·δ(t−t')
```

### 3.2 耗散项 −γv 的社会含义

- **知识遗忘与技术失传**：文明衰退期的技术退化（如罗马帝国崩溃后的欧洲）
- **制度腐化**：官僚体系效率随时间下降
- **资源消耗与环境退化**：过度开发导致承载力下降
- **个体衰老与死亡**：人的生命周期本身就是能量耗散过程

### 3.3 随机力 ξ(t) 的社会含义

- **天才人物的随机出现**：孔子、亚历山大、牛顿
- **自然灾害**：地震、干旱、洪水
- **战争中的偶然事件**：关键战役的胜负、主帅的意外阵亡
- **生老病死的随机性**：个体生命的不确定性

### 3.4 温度 T 的社会解读

- **高温态**：战乱年代、大航海时代、技术革命期——制度变迁概率高
- **低温态**：稳定的王朝中期——制度固化
- **温度可以是时空变量 T(x, t)**：在 BBK 积分器中体现为热噪声强度（配置项 `temperature`），可与耗散系数联调涨落–耗散比
- **温度与 ε 的耦合**：ε 跃迁可能引发有效温度的突变

**与「环境气候」的区分**：除上述 Langevin **动力学温度**外，仿真另有**气候子系统**（年均温、降水等空间场，见 §5.7 与 §9.3），用于调制资源产出、承载力、额外死亡率、动量阻尼与瘟疫触发率。二者符号均可能出现「温度」一词，但物理含义不同：前者为随机动力学强度，后者为地理环境变量。

### 3.5 涨落-耗散定理的社会解读

> *一个社会的创新能力（涨落）与其制度损耗（耗散）是成正比的。*

- 清朝晚期：制度僵化（低耗散）伴随创新停滞（低涨落）
- 战国时期：诸侯争霸（高耗散）伴随百家争鸣（高涨落）

### 3.6 Kramers 逃逸理论 → 制度变迁的概率

```
r ∝ exp(−ΔV / k_B·T)
```

- 制度变迁需要跨越势垒 ΔV
- 温度 T 越高，变迁概率越大
- **重大制度变革往往发生在乱世**
- **ε 跃迁降低势垒**：新能量利用方式改变势能面拓扑

### 3.7 开放系统：粒子产生与湮灭

人口的生老病死使系统不满足粒子数守恒：

- **出生**：满足繁殖条件时（详见 2.5 节），在母体附近注入新粒子，继承父代属性 + 随机变异
- **死亡**：四重机制——衰老（Gompertz）、饥饿（w < 阈值）、意外（P_accident 常数）、瘟疫（差异化免疫）
- **迁徙**：粒子在势能面上漂移，倾向于从高势能区流向低势能区
- **马尔萨斯约束**：局部人口密度不能长期超过资源承载力 K(x)

### 5.2 自由度的哲学推导（★★★★☆）

### 5.3 能量利用能力 ε 作为文明演化驱动力（★★★★★）

ε 的引入带来三重价值：乘性耦合改变有效耦合常数、跳跃-扩散数学结构、ε 跃迁触发社会制度相变。

### 5.4 文化向量与群体认同涌现（★★★★☆）

d 维文化向量 c⃗ 使群体边界从动力学中自然涌现。繁殖的文化兼容性条件使文化隔离→生殖隔离→文化进一步分化，形成正反馈。

### 5.5 完整的人口动力学模型（★★★★☆）

包含生育能力曲线、妊娠冷却期、资源门槛、马尔萨斯反馈、代际遗传与变异。ε 跃迁突破承载力天花板，触发新一轮人口增长→社会结构重组。

### 5.7 高分辨率真实地形与气候场（★★★☆☆）

**长期目标**：将地形抽象为一般形式的势能面，纳入坡度、河距、土壤肥力等多源地理因子：

```
V_terrain(x,y) = f(elevation, slope, river_proximity, soil_fertility, ...)
```

#### 5.7.1 已实现：DEM 栅格与多通道耦合

当前代码以 **数字高程 $h(x,y)$** 为主（ETOPO 等 DEM 经 `scripts/fetch_terrain.py` 转为 ESRI ASCII，或由 `terrain_type = river | continent | …` 生成合成栅格），在 Politeia 中与粒子动力学耦合如下：

| 通道 | 机制概要 |
|------|-----------|
| **运动力** | 若已加载 `TerrainGrid`，BBK 积分器**每步**累加网格地形力 $\mathbf{F}=-\mathrm{scale}\,\nabla h$（与社交力叠加）；否则回退解析 **Gaussian wells**。 |
| **资源势（产出）** | 定义 $V_{\mathrm{res}}(x,y)=-\mathrm{scale}\cdot(h_{\max}-h)$，河谷 $V_{\mathrm{res}}<0$；本地资源率 $R(x)\propto \max(0,-V_{\mathrm{res}})$，进入 $\mathrm{d}w/\mathrm{d}t$（并与技术 $\varepsilon$ 相乘）。 |
| **承载力** | $K(x)\propto \max(0,-V_{\mathrm{res}})$，与局部密度共同给出拥挤因子。 |
| **交流阻抗（可选）** | 对称资源交换中，对势差施加 $\exp\bigl(-|V_{\mathrm{res},i}-V_{\mathrm{res},j}|/h_0\bigr)$，模拟跨山脊/谷地的有效阻隔（`terrain_barrier_enabled` / `terrain_barrier_scale`）。 |

海洋势垒、沙漠细粒度区分等仍属**数据与后处理扩展**；当前实现以「高程 → 势能与梯度」为统一接口。

#### 5.7.2 已实现：RiverField 河流走廊场

为解决“**山脉适合粗格、河流需要细格**”的尺度冲突，当前实现将**背景地形**与**水系走廊**拆成两层：

- **`TerrainGrid`**：粗尺度背景场，负责山脉/高原/平原/盆地的势垒、梯度力与背景承载。
- **`RiverField`**：独立栅格场，当前以 **river proximity** 为主（并为 `discharge` 预留接口），负责“靠近大河更高产、更易连通”的走廊效应。

这种拆分避免把河流硬塞进粗 DEM，导致尼罗河谷、两河走廊等细结构在地形重采样时被抹平。

当前 `RiverField` 在 Politeia 中的耦合方式为：

| 通道 | 机制概要 |
|------|-----------|
| **资源加成** | 沿河 proximity 对本地产出率施加乘性加成：$R_{\\mathrm{total}}(x)=R_{\\mathrm{terrain}}(x)\\cdot(1+s_r\\,p(x)^\\alpha)$。 |
| **承载提升** | $K_{\\mathrm{total}}(x)=K_{\\mathrm{terrain}}(x)\\cdot(1+s_K\\,p(x)^\\beta)$，形成沿河聚落带。 |
| **交换走廊** | 成对资源交换中乘以 `river_pair_bonus = 1 + s_e \\min(p_i,p_j)`，表达“同在河网走廊上的群体更易交换”。 |
| **技术传播** | 接触传播项 `spread_rate` 按双方 proximity 的最小值放大，模拟沿河知识/工艺扩散更快。 |
| **瘟疫增强（可选）** | 若打开 `river_plague_enabled`，则近河区域提高瘟疫触发与感染概率，模拟水系/湿润走廊的传播通道效应。 |
| **弱迁移偏置（可选）** | 若打开 `river_force_enabled`，则按 proximity 梯度施加很弱的动量修正，使迁移轻微偏向河道；默认关闭，避免“所有人被吸进河里”的非物理行为。 |

这里的河流场是**独立于 `TerrainGrid::potential()` 语义之外**的第二环境层，不参与当前地形势的定义；也就是说，地形仍主要表达“障碍”，河流主要表达“走廊”。

#### 5.7.3 已实现：气候栅格与区域依赖

为刻画**纬度、降水与宜居带**对文明承载的影响，引入 **ClimateGrid**（`climate_mode = procedural | file`）：

- **程序化模式**：由纬度给出基准年均温与降水型式，若有 `TerrainGrid` 则叠加海拔递减与高山减湿；无需外场文件即可全球运行。
- **文件模式**：双波段 ESRI ASCII（先温度 ℃、后降水 mm），可由 `scripts/fetch_climate.py` 生成或外部再处理。
- **时变**：`climate_time_mode = static | drift | seasonal`，支持全局温度偏移随步数漂移或季节项；可配分段表 `climate_drift_schedule`。
- **与社会模块的耦合（乘性/加性因子）**：在适宜温湿区放大产出与承载力；**恶劣度**函数综合偏温、偏旱，驱动额外死亡风险、步后动量阻尼（等效摩擦升高）、以及瘟疫触发率的区域调制（具体实现见 `src/climate/` 与主循环）。

Köppen–Geiger 分类栅格的**自动下载与整图对齐**仍在工具链演进中；文件模式已预留。

## 六、观测量与序参量：如何检测阶级和制度的涌现

> 代码实现 → [[CODE_GUIDE#7. `analysis/` — 序参量与观测]]
> 物理验证标准 → [[DEVELOPMENT_PLAN#6.3 物理验证（贯穿所有阶段）]]

模拟的核心挑战不仅是"能否涌现社会结构"，更是"如何定量判断涌现了什么"。需要定义明确的**序参量（order parameter）**来检测阶级出现、层级形态和制度类型——正如物理学中用磁化强度区分铁磁相和顺磁相。

### 6.1 第一层：阶级是否涌现——不平等度量

#### (1) Gini 系数 G(t)

将所有个体的 w_i 排序后计算 Lorenz 曲线下面积：

```
G = 0    → 完全平等（所有人财富相同）
G = 1    → 完全不平等（一个人拥有全部）
```

持续追踪 G(t)，当 G 从接近 0 **突然上升**时，就是阶级涌现的信号。若上升是不连续的（类似相变中序参量的突变），则具有明确的物理意义。

#### (2) 财富分布形态 P(w)

不仅看 Gini，还要看完整的分布函数：

```
P(w) ~ exp(−w/w₀)        → Boltzmann 分布（交换经济，弱分层）
P(w) ~ w^(−α)             → Pareto 幂律（强分层，阶级固化）
P(w) 出现双峰             → 明确的两个阶级（富人-穷人二元结构）
```

分布形态的**转变**就是相变的信号：从指数分布到幂律分布对应"无阶级→有阶级"。

#### (3) 阶级流动性 M(t)

Gini 不能区分"有阶级但流动"（如科举制）和"阶级完全固化"（如种姓制）。定义：

```
M(t) = 1 − corr(rank_w(t), rank_w(t + Δt))
```

```
M ≈ 0 → 阶级固化（你爸是农民你就是农民）
M ≈ 1 → 完全流动（财富排名每代完全重洗）
```

### 6.2 第二层：层级结构的形态——依附网络分析

依附指针 superior_i 构成一个**有向森林**（多棵树）。对这个图做网络分析：

#### (4) 层级深度 H(t)

```
H(t) = 依附树的最大深度
```

```
H = 0  → 无层级（人人平等的原始群体）
H = 1  → 仅有头领（简单酋邦）
H = 2-3 → 头领-贵族-平民（早期封建）
H = 5+ → 深层官僚体系（帝国/郡县制）
```

#### (5) 层级树的分支因子 B(t)

```
B(t) = 非叶节点的平均子节点数
```

```
B 大, H 小 → 扁平结构（联邦/城邦联盟：头领直辖很多人，但层级浅）
B 小, H 大 → 深层结构（官僚帝国：每层管辖少数下级，但层级深）
```

#### (6) 最大连通分量比 F(t)

```
F(t) = 最大依附树中的人数 / 总人数
```

```
F ≈ 0         → 原子化社会（无组织）
F ∈ (0.1, 0.3) → 若干中型政治实体并存（城邦/诸侯国）
F > 0.7       → 一个政治实体支配（统一帝国）
```

#### (7) 独立政治实体数 C(t)

```
C(t) = 没有 superior 的"根节点"数量（即"国家"数量）
```

```
C 减少 → 兼并/统一
C 增加 → 分裂/叛乱
C = 1  → 天下一统
```

### 6.3 第三层：制度类型的辨别——复合序参量

单一指标无法区分制度类型。需要**组合多个序参量**构成"制度相空间"。

#### (8) 分封度-集权度序参量 Ψ(t)

区分"分封制"和"郡县制"的核心序参量。定义"二级节点的平均自治度"：

```
Ψ = ⟨ w_lord / w_subtree ⟩    （二级节点自身资源 / 其子树总资源）
```

```
Ψ ≈ 1  → 分封制（诸侯拥有独立的资源控制权，子树资源≈诸侯个人资源）
Ψ ≈ 0  → 郡县制（地方官不拥有资源，只是代理人，子树资源远大于官员个人）
```

物理类比：Ψ 类似于铁磁体的磁化强度 M。Ψ 从 ~1 到 ~0 的转变就是"分封→郡县"的相变。

#### (9) 集群大小分布 n(s)

统计所有独立政治实体的大小（人数）分布：

```
n(s) ~ δ(s − s₀)     → 所有城邦大小一致（希腊城邦式均匀分布）
n(s) ~ s^(−τ)         → 幂律分布（临界态：诸侯争霸，大小不一）
n(s) ~ δ(s − N)       → 一个巨型实体（统一帝国）
```

这与**渗流理论 (percolation theory)** 直接对应：
- 临界点以下 → 很多小集群（分裂状态）
- 临界点 → 幂律分布的集群大小（争霸/过渡态）
- 临界点以上 → 一个巨大连通分量涌现（统一）

#### (10) 空间关联函数 g(r)

类似液体物理中的径向分布函数：

```
g(r) = ⟨ρ(x)·ρ(x+r)⟩ / ⟨ρ⟩²
```

```
g(r) ≈ 1（对所有 r）  → 均匀分布（游猎状态）
g(r) 有明显峰值        → 聚落结构（城市-乡村交替）
g(r) 长程有序          → 帝国级的空间组织
```

#### (11) 文化序参量 Q(t)

测量文化向量的全局有序度：

```
Q(t) = |⟨ĉ_i⟩|    （所有个体文化方向的平均模）
```

```
Q ≈ 0  → 文化多样性高（各方向均匀分布）
Q ≈ 1  → 文化高度统一（所有人方向一致，"大一统"）
```

局部文化序参量 Q(x, t) 可以揭示文化圈的空间边界。

### 6.4 制度相图：用序参量识别社会"相"

将多个序参量组合，构成**制度识别表**：

| 制度类型 | G (Gini) | H (层级深度) | B (分支因子) | F (最大分量比) | C (实体数) | Ψ (分封度) | Q (文化统一) | ⟨L⟩ (平均忠诚度) |
|---|---|---|---|---|---|---|---|---|
| 原始群体 | < 0.2 | 0 | — | ~0 | 很多 | — | 低 | — |
| 酋邦 | 0.2–0.4 | 1–2 | 大 | 0.05–0.15 | 多 | ~1 | 低-中 | 高（个人魅力型） |
| 诸侯分封 | 0.4–0.6 | 2–4 | 中 | 0.3–0.6 | 少（>1） | ~1 | 中 | 中（层级越远越低） |
| 中央集权帝国 | 0.5–0.8 | 5+ | 小 | > 0.7 | 1–2 | ~0 | 高 | 中-高（制度维系） |
| 城邦联盟 | 0.3–0.5 | 1–3 | 大 | 0.05–0.2 | 多（大小接近） | ~1 | 低 | 高（城邦内部高） |

当模拟输出的序参量组合**从一行跳到另一行**时，就发生了**社会相变**。

### 6.5 相变的检测方法

#### 序参量的时间序列突变

持续追踪所有序参量随时间的演化。当某个序参量发生不连续变化或急速变化时，标记为相变候选事件。

#### 涨落的发散

物理学中，相变点附近序参量的涨落会发散。类似地，在社会相变（如统一前的诸侯争霸期）附近，预期 G(t)、F(t)、C(t) 的方差急剧增大。

#### 关联长度的发散

相变点附近，空间关联函数 g(r) 的关联长度趋于发散——对应"一个政治事件影响越来越远的地方"（如战国末期的连横合纵波及全天下）。

## 七、观测与分析方法：如何看到涌现

第六章定义了**测什么**（序参量），本章定义**怎么看**（可视化、分析管线和自动检测）。

### 7.1 实时空间可视化

将粒子画在地形势能面上，用颜色和大小编码属性：

```
画布：地形势能面（等高线/灰度底图）
粒子位置：每个人一个点
颜色编码（可切换）：
  按 w_i 着色   → 看财富的空间分布（红=富，蓝=穷）
  按 ε_i 着色   → 看技术的空间扩散
  按 c⃗_i 方向着色 → 看文化圈的边界（不同颜色=不同文化）
  按 subtree 着色  → 看政治实体的疆域（同色=同一"国家"）
点的大小：∝ w_i 或 Power_i
```

生成动画（每 N 步输出一帧），可以直观看到人口聚集、财富分层、文化圈形成、政治实体扩张与崩溃的完整过程。

### 7.2 序参量时间序列

持续记录所有序参量，画时间序列图。关键信号：

- G(t) 突变上升 → 阶级涌现
- G(t) 突变下降 → 王朝崩溃后的重新平等化
- C(t) 持续下降 → 兼并/统一进程
- C(t) 突变上升 → 帝国分裂
- H(t) 突然增加 → 层级复杂化（如从部落到国家）
- ⟨L⟩(t) 持续下降 → 王朝衰落预警
- 多个序参量同时突变 → **相变事件**

### 7.3 分布函数分析

定期（每 M 步）计算并输出分布函数：

**财富分布 P(w)**

在 log-log 图上绘制 P(w)：
- 弯曲下降 → 指数分布（弱分层，早期社会）
- 直线下降 → 幂律分布（强分层，Pareto 尾）
- 出现双峰 → 明确的二元阶级结构

通过拟合提取 Pareto 指数 α(t)，追踪其随时间的演化。α 从大变小 → 不平等加剧。

**集群大小分布 n(s)**

渗流分析：
- n(s) 指数衰减 → 临界点以下（很多小"国家"）
- n(s) ~ s^(−τ) 幂律 → 临界点（争霸态/过渡态）
- 一个巨型集群主导 → 临界点以上（统一）

### 7.4 交互网络分析（层级涌现的核心检测手段）

在不预设 superior_i 的阶段 1-3 中，这是检测层级是否涌现的核心方法。

**步骤 1：构建交互网络**

```
每 T 个时间步统计：
  对每对个体 (i, j)：
    net_flow(i→j) = Σ(j→i的资源流) − Σ(i→j的资源流)
  
  if net_flow(i→j) > threshold：
    画有向边 i → j（i 事实上从 j 获取资源）
```

**步骤 2：分析网络拓扑**

```
度分布 P(k)：
  均匀  → 无层级
  幂律  → 少数"枢纽"控制大量连接 → 层级涌现

树性检测：
  最大连通分量的边数 ≈ 节点数 − 1 → 清晰的树状层级
  大量环路 → 复杂的权力网络（非简单层级）

中心性分析：
  betweenness centrality 的分布 → 是否存在关键"枢纽"节点
```

**步骤 3：可视化**

用力导向布局画出网络图，节点大小 ∝ 净资源流入，边粗细 ∝ 流量。如果出现星形结构（一个中心连接很多外围），就是层级的视觉证据。

### 7.5 空间关联分析

**径向分布函数 g(r)**

```
对所有粒子对按距离分桶，归一化得 g(r)
  g(r) ≈ 1      → 均匀分布（游猎状态）
  g(r) 小 r 处峰 → 聚落结构
  g(r) 多峰     → 城市间距的规律性
```

**文化空间关联**

```
C_culture(r) = ⟨c⃗_i · c⃗_j⟩ / (|c⃗_i| · |c⃗_j|)    对 |x_i − x_j| = r 的粒子对

C_culture(r) 衰减到 0 的距离 = 文化关联长度 ξ_c
  ξ_c 小  → 文化是局域的（部落级别）
  ξ_c 大  → 文化统一（帝国级别）
  ξ_c 发散 → 文化统一的相变点附近
```

### 7.6 相图构建

通过参数扫描构建制度相图：

```
固定其他参数，扫描 (T, ε) 二维参数空间：
  对每个 (T, ε) 组合运行模拟至稳态
  记录稳态下的序参量组合 (G, H, F, C, Ψ)
  用制度相图表（6.4 节）分类
  着色绘制相图

预期结果：
  高 T, 低 ε → 部落相（高涨落，无法形成稳定层级）
  低 T, 低 ε → 酋邦/小国相
  低 T, 中 ε → 诸侯/帝国相
  高 T, 高 ε → 动态竞争相
```

相图中不同相的边界就是**相变线**，可以与 Kramers 理论的预测对比。

### 7.7 相变事件的自动检测

在模拟运行时实时识别相变：

```
对每个序参量 X(t)：
  变化率:  dX/dt（滑动窗口内的平均斜率）
  涨落:    Var(X)（滑动窗口内的方差）
  
  if |dX/dt| > threshold_rate → 标记"快速变化事件"
  if Var(X) > threshold_var  → 标记"涨落发散事件"（相变前兆）
  if 多个序参量同时触发     → 标记"相变事件"
  
  记录：事件时间、空间位置、变化前后的序参量值、触发机制
```

```
模拟运行

  ├→ 每步输出：粒子状态快照文件 (x, p, w, c⃗, ε, a)
```

## 九、技术路线

### 9.1 个体状态与交互设计

**状态向量**：Z_i = (x_i, p_i, w_i, c⃗_i, ε_i)，参数 a_i，附属属性 d⃗_i
**拓扑信息**：依附指针 superior_i + 忠诚度权重 L_ij
**派生量**：武力 s_i = f(w_i, ε_i)，有效权力 Power_i = Σ w_j × L_path

**个体间交互**：
- 空间交互：短程吸引 + 超短程排斥（类 Lennard-Jones）→ 驱动聚集
- 财富交互：碰撞式交换，不对称（强者获益更多）→ 驱动分层
- 文化交互：接触传播，c⃗ 趋同（文化距离小时合作，大时排斥）→ 文化圈形成
- 技术传播：高 ε 向低 ε 传播，受地形势垒阻隔
- **阶段 1-3 不含以下机制**（验证涌现后再引入）：
- （阶段 4+）依附形成：从交互网络中检测到稳定的单向资源流后，显式建立 superior_i
- （阶段 4+）忠诚度演化：L_ij 受保护/剥削/文化距离/噪声驱动
- （阶段 4+）税收/保护：上级从子树提取资源，同时提供保护
- 繁殖交互：满足五条件时产生新粒子（详见 2.5 节）
- 瘟疫传播：携带者接触无免疫群体时传播（详见 2.3 节）

### 9.2 势函数设计（核心难点）

**第一阶段**：LJ 势 + 背景地形势 + 河流走廊场
```
V_ij = 4ε_LJ [(σ/r_ij)^12 − (σ/r_ij)^6]
V_ext(x) = V_terrain(x)
R_total(x) = R_terrain(x) × f_river(proximity)
```

**第二阶段**：加入文化向量依赖的交互项
```
V_culture(i,j) = V_0 · (1 − exp(−|c⃗_i − c⃗_j|² / 2σ_c²))
```

**第三阶段**：加入 ε 耦合项

### 9.3 地形、河流与气候数据

#### 地形

> 数据获取工具 → `scripts/fetch_terrain.py`

- **数据源**：ETOPO1 全球地形（NOAA NCEI, 1'×1' 分辨率）、SRTM DEM、Natural Earth
- **配置**：`terrain_type = grid` 且 `terrain_file` 非空时读入栅格；`terrain_format = binary` 时需同时给出 `terrain_grid_rows` / `terrain_grid_cols`；其余 `terrain_type`（如 `river`、`continent`）在域上生成固定分辨率的**合成栅格**（当前主程序为 128×128），或回退 `gaussian` 解析势阱。
- **与引擎的衔接**：栅格加载后，**地形力进入 BBK 每步子步的力计算**；`terrain_scale` 统一缩放「力」与「资源/承载用势」的强度。
- 河流/平原（低 $h$）→ 低势（资源意义下 $V_{\mathrm{res}}<0$）+ 高 $R(x)$；山脉（高 $h$）→ 梯度力指向谷地 + 低 $R(x)$；海洋可在预处理 DEM 中抬升为不可达区（实现层面依数据而定）。
- **格式**：ESRI ASCII Grid (`.asc`) 或行主序 float64 裸二进制，与 `TerrainGrid::load_ascii` / `load_binary` 一致。

#### 河流

> 数据获取工具 → `scripts/fetch_rivers.py`

- **定位**：河流不再作为“必须从 DEM 中看出来的细地貌”，而是作为与地形并列的 **RiverField** 独立场接入。
- **配置**：`river_enabled`、`river_mode`（`procedural` | `file`）、`river_file`、`river_format`、`river_grid_rows` / `river_grid_cols`、`river_type`，以及各耦合通道开关与强度（`river_resource_*`、`river_capacity_*`、`river_exchange_*`、`river_tech_*`、`river_plague_*`、`river_force_*`）。
- **程序化河流**：当前可按区域生成 major-rivers / nile / mesopotamia / china / europe / indus 等近似主河网 proximity 场，默认按域宽高比生成规则栅格。
- **文件模式**：当前第一版以**单波段 proximity ASCII / binary** 为主；接口已为 `discharge` 预留扩展。后续若需要，可演进为双波段 ASCII（proximity + discharge）。
- **耦合职责**：河流主要负责资源走廊、承载提升、交换与技术传播的低成本连接、以及可选的瘟疫增强与弱迁移偏置；**不默认承担主地形力**。

#### 气候

> 数据获取工具 → `scripts/fetch_climate.py`（程序化生成或双波段 ASCII；Köppen 自动下载为预留路径）

- **配置**：`climate_enabled`、`climate_mode`（`procedural` | `file`）、`climate_file`、`climate_time_mode`（`static` | `drift` | `seasonal`）、`climate_drift_rate`、`climate_drift_schedule`、`climate_season_amplitude`、`climate_season_period`、`climate_update_interval`，以及各通道开关与强度（`climate_*_enabled`、`climate_*_scale`）。
- **程序化气候**：默认在全球域上生成 **128×256**（纬×经向格点数）气候场；若存在 `TerrainGrid`，生成时传入指针以做海拔修正。
- **耦合**：产出与承载力乘性因子、恶劣环境下的额外死亡与动量阻尼、瘟疫触发率采样加权（详见 §5.7.2）。

### 9.4 数值方法

- **积分器**：随机 Velocity-Verlet 或 BBK 积分器，外加 Poisson 跳跃的事件驱动处理
- **时间步长**：需根据 γ 和势能曲率确定稳定性条件
- **随机数生成**：高质量伪随机数生成器，高斯白噪声 + Poisson 过程
- **温度控制**：Langevin 方程中的 **T** 为动力学噪声强度（配置项 `temperature`）；**环境意义上的气温场**由气候模块单独给出，二者勿混用（见 §3.4）

### 9.5 计算方案

> 大规模并行方案 → [[docs/parallel-framework-design]]
> MPI + SoA 实现 → [[DEVELOPMENT_PLAN#1.1 数据布局：SoA（Structure of Arrays）]]

- **个体级模拟**：每个粒子代表一个人，初始规模 10⁴–10⁵（标准算例 10 万粒子，表示比 1:45）
- **并行化**：MPI 区域分解（Morton Z-order SFC）+ 弹性 Checkpoint/Restart 支持进程数弹性伸缩（详见 [[docs/parallel-framework-design]]）
- **开放边界**：粒子产生-湮灭处理人口动态
- **邻居列表**：Verlet list 或 cell list 加速短程力计算
- **初始条件**：HYDE 3.3 校准的标准算例体系，29 个考古文化区（详见 §9.5.1）

#### 9.6.1 设计哲学

模型中的每一条交互规则——交换公式、征服条件、忠诚度方程、生育门槛——本质上都是一个**可证伪的假说**。我们无法从第一性原理推导出社会交互的精确函数形式，因此必须将规则本身作为实验变量。

这要求将所有机制模块化、参数化，通过配置文件控制每个模块的开关和参数，使得：

1. **消融实验**（ablation study）：逐个开关模块，观察哪些规则对涌现结果影响最大
2. **参数扫描**（parameter sweep）：在规则参数空间中系统搜索，定位产生历史可比涌现模式的参数区域
3. **规则组合实验**：测试不同规则组合下的涌现差异，回答"哪些微观机制是文明演化的关键驱动力"

| C1-C6 | 各实验 × china 地形 | 不同规则下中国地形是否一致趋向统一？ |

每个实验运行多个随机种子（建议 ≥ 5 次）取统计平均，对比稳态序参量 (G, H, C, F, Ψ, HHI)。

### 9.7 推荐的原型路线（涌现优先）

原型路线遵循"涌现优先"原则：先用最少的对称规则验证涌现，再逐步引入精细化机制。

**第一期：纯对称规则，验证涌现（阶段 1-3）**

不含任何预设的层级机制（无 superior_i、无 L_ij、无 Power_i、无"胜者更强"规则）。所有交互规则都是对称的。目标是验证不平等和层级能否从对称规则中自发涌现。

1. **最小原型**：~1000 个 agent，简化地形（2D 高斯势阱），仅 (x, p, w) 三个自由度，固定温度，对称资源交换。**核心问题：Gini 系数是否自发上升？**
2. **文化阶段**：加入 c⃗_i，观察文化圈边界和群体认同是否涌现。通过交互网络分析事后检测是否出现持续的单向资源流（"事实支配关系"）。
3. **繁殖+Langevin 阶段**：引入人口动力学和耗散/随机力。验证马尔萨斯反馈、人口稳态。在交互网络中观察层级深度 H(t) 是否自发从 0 开始增长。

**第二期：层级精细化（阶段 4），仅在涌现被确认后引入**

4. **层级精细化阶段**：如果第一期确认层级涌现，引入 superior_i 指针和忠诚度 L_ij 作为对已涌现层级的精细化描述。引入 Power_i 派生量。观察叛乱/王朝更替是否自发发生。

**第三期：完整模型（阶段 5-7）**

5. **能量利用阶段**：引入 ε_i 和 Poisson 跳跃，观察 ε 跃迁是否触发人口增长和制度相变。
6. **地形阶段**：引入真实 DEM 地形，验证文明起源的地理规律。
7. **大规模阶段**：扩大至 10⁵ 粒子，引入瘟疫模块，模拟千年尺度的文明演化。

## 十、潜在风险与应对

1. **涌现偏见**：模型设计可能预设了层级的出现（如内置依附指针、胜者更强规则），导致"涌现"只是预设的自我实现。应对：采用"涌现优先"方法论（详见 2.6 节），阶段 1-3 仅使用对称规则，不含任何层级机制，验证层级是否自发涌现后再引入精细化描述。
2. **势函数的任意性**：社会系统无第一性原理可推导势函数。应对：用已知历史规律做反演校准。
3. **自由度选择的主观性**：虽有哲学论证，但"不可约"判断仍有主观性。应对：从最少自由度开始逐步增加。
4. **文化向量维度 d 的选择**：d 太小无法区分足够文化类型，d 太大增加计算量。应对：从 d=2 开始。
5. **可证伪性**：模型需做出可检验预测。应对：聚焦定量可验证的预测。
6. **Langevin 近似的适用性**：白噪声假设可能不够。应对：可扩展为广义 Langevin 方程（GLE）。
7. **计算规模**：个体级模拟计算量巨大。应对：初期 10⁴–10⁵ 规模，GPU 加速。
8. **ε 跳跃的参数化**：缺乏先验约束。应对：以历史技术突破时间间隔校准。
9. **繁殖模型参数**：生育曲线、冷却期等参数需参考人口学数据校准。应对：使用联合国人口数据和历史人口学研究。
10. **配置空间组合爆炸**：可配置的模块和参数数量庞大，全组合扫描不现实。应对：采用分层实验策略——先做模块级消融（开/关），锁定关键模块后再对其参数做细粒度扫描；利用拉丁超立方采样等高效空间填充方法减少实验次数。

## 十一、研究定位

> **用 Langevin-跳跃扩散动力学在真实地形势能面上模拟个体人类的演化，以哲学推导的不可约自由度——在（x）、有（w）、知（c⃗）、能（ε）——描述每个人，结合完整的人口动力学（繁殖、死亡、代际传承）和差异化瘟疫模型，研究能量利用能力的跃迁如何驱动社会制度的相变，从个人到部落到帝国的完整涌现链条。**
