审查关注点：Gate 能保证什么 vs 不能保证什么

✓ Gate 能验证（结构层）

  • 证据文件存在 / 非空 / SHA 匹配
  • claim→finding→paper 三层闭环
  • commit 非 dirty、seed 数量、exit_code=0
  • 无 NaN/Inf、路径不逃逸

✗ Gate 验证不了（科学层）

  • 实验设计是否有偏、baseline 是否公平
  • 统计检验是否恰当、结论是否过度外推
  • config 只查"存在任意 yaml/json"→ 可被空壳文件满足
  • REVIEW 与写作 Agent 同源 → 共同盲区

⚠ 工程隐患

  • WRITE-COMPREHENSIVE 阶段无审稿
  • 项目根在 OneDrive 同步盘 ↔ SHA 复现性冲突
  • 多 JSON 契约一致性维护成本
  • 绿灯 ≠ 科学成立（结构性上限）
