# 期刊格式规则

定义 Nature、PRL 等顶刊的格式要求和提炼策略，供 WRITE-JOURNAL Agent 在从完整论文
浓缩期刊版本时参考。

## Nature

Nature 发表面向全体科学家的研究文章，要求具有广泛的跨领域意义。

### 格式要求

| 维度 | 要求 |
|------|------|
| 正文字数 | ~2,500 词（不含方法、参考文献、图例） |
| Display items | 3-4 个图表 |
| 摘要 | ~150 词，独立段落，无引用 |
| 章节结构 | 无显式标题的流式叙事（引言→结果→讨论），末尾有 Methods |
| 参考文献 | 30-50 条为佳 |
| 补充材料 | 详细方法、额外数据放 Supplementary Information |

### 叙事策略

1. **第一段即定调**：用 2-3 句话交代大问题，再用 2-3 句话说本文做了什么、为什么重要。
   不要让读者等到第二页才知道这篇论文的价值。
2. **广泛吸引力**：motivation 部分要解释清楚为什么非本领域的科学家也应该关心这个结果。
   Nature 编辑桌拒稿的首要原因就是"不够 broad"。
3. **单一核心叙事**：围绕一个核心发现构建全文，次要结果合并成一句话或放入 SI。
4. **结果先行**：开头直接呈现最重要的发现，再回溯方法和背景。
5. **避免行话**：能用通俗词就不用术语；必须用术语时首次出现就要解释。
6. **Discussion 要有远见**：不仅讨论局限性，还要展望这个发现可能开启的研究方向。

### 提炼清单

WRITE-JOURNAL 在生成 Nature 版本时必须检查：

- [ ] 正文是否 ≤ 2,500 词（不含方法和参考文献）
- [ ] 是否有 3-4 个 display items
- [ ] 第一段是否同时涵盖"大背景"和"本文贡献"
- [ ] 是否避免使用本领域以外的科学家看不懂的术语
- [ ] 核心结论能否用一句话让不同领域的科学家理解
- [ ] 所有实验结果是否只保留支撑核心叙事的、次要的放 SI
- [ ] Methods 是否独立成节、在正文末尾
- [ ] 参考文献是否包含足够的跨领域引用（不仅限于本子领域）

## Physical Review Letters (PRL)

PRL 发表物理学各分支的重大突破，读者是全体物理学家。

### 格式要求

| 维度 | 要求 |
|------|------|
| 正文字数 | ≤ 3,750 词（约 4 页 PRL 格式） |
| 摘要 | ~150 词 |
| Display items | 3-4 个图，可含小表格 |
| 章节结构 | 引言 → 主体 → 结论（可用标题也可不用） |
| 参考文献 | 建议 ≤ 30 条 |
| 补充材料 | Supplemental Material 放推导、额外数据 |

### 叙事策略

1. **一个重大结果**：PRL 的核心标准是"该结果是否值得全体物理学家的关注"。一个深刻的
   单一结果远胜过三个停留在表面的结果。
2. **物理直觉**：强调物理图像而非数学技巧。方程之后必须用文字解释物理含义。
3. **引言定位精准**：第一句说大领域，第一段未说本文要解决的 gap，第二段说本文做了什么。
4. **方法在正文中适度展开**：PRL 不像 Nature 那样把方法全部塞到 SI，但也不用像
   full paper 那样详尽。关键推导保留，细节放 Supplemental。
5. **与 prior work 的对比**：明确说明本文结果与已有文献的区别和进展，不做模糊宣称。
6. **结论克制**：PRL 审稿人反感 overclaim。宣称必须严格对应证据。

### 提炼清单

WRITE-JOURNAL 在生成 PRL 版本时必须检查：

- [ ] 正文是否 ≤ 3,750 词
- [ ] 是否有 3-4 个 figures
- [ ] 摘要是否 ≤ 150 词、独立成段
- [ ] 是否聚焦在**一个**重大物理结果上（而非多个分散结果）
- [ ] 物理图像是否清晰（公式后有物理解释）
- [ ] 引言是否在第一段末尾设立了 gap，第二段交代了贡献
- [ ] 是否与 prior work 做了具体对比（而非笼统说 better）
- [ ] conclusions 是否严格对应证据，无 overclaim
- [ ] Supplemental Material 是否包含了完整推导和数据

## 通用提炼原则

### 核心法则：先删后改

从完整论文提炼期刊版本时，按以下顺序操作：

1. **筛选 claim**：完整论文可能有 5-7 个 claim，期刊版本只保留最核心的 1-2 个。
2. **删实验**：与核心 claim 不直接相关的实验删除；支撑性实验浓缩为 1-2 句话放正文或移入 SI。
3. **缩方法**：砍掉所有非关键实现细节，只保留对理解结果必要的方法描述。
4. **简讨论**：将多方向的讨论收敛到单一叙事线；limitations 保留最关键 1-2 条。
5. **调语言**：在科学准确性不变的前提下，调整措辞以匹配目标期刊的读者群和 tone。

### 内容一致性约束（不可违反）

1. 期刊版本中的每个 claim 和结果必须能在完整论文中找到对应。
2. 不得在浓缩时"拔高"结论（如将 limitation 变成 finding）。
3. 不得省略关键限制条件（如参数范围、样本量、统计显著性）。
4. 数值结果必须与完整论文一致（含小数位和有效数字）。

### 期刊选择指南

| 特征 | 推荐期刊 |
|------|----------|
| 跨领域重大发现，任何科学家都想了解 | Nature / Science |
| 物理学重大突破，改变了对某个基本问题的理解 | PRL |
| 多个重要但非革命性的结果，方法上有创新 | Nature Physics / PRX |
| 方法学为主，应用广泛 | Nature Methods |
| 领域内重要进展 | 各领域顶刊（ApJ、JHEP、PRD 等） |

项目可在 `project.json` 的 `journals` 字段中增减目标期刊：

```json
{
  "journals": ["nature", "prl"]
}
```

Agent 会根据 `journals` 列表自动生成对应版本。未列出的期刊不生成。
